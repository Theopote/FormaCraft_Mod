# 社区下载入库确认

下载成功只生成私人缓存。用户先点击“查看入库信息”，服务器在既有有界工作池中重读当前下载收据，校验描述符、原包、环境和来源；返回名称、尺寸、方块数、作者/许可/训练授权声明及发布身份。此步骤不修改构件库。

“确认入私人库”只接受当前玩家、会话内当前成功预览任务的随机标识。从预览任务创建起有效 120 秒，不接受客户端路径、收据或包描述符。新的搜索、下载、会话、取消或配置重载使旧确认失效；重复确认不能重复启动写入。后台再次读取与核对原包，通过最后一次会话检查后获得入库许可，再调用 ComponentSourceBinding.install，始终写入玩家私人库。相同内容复用既有资产并保留所选来源，名称不参与覆盖判定。

获得入库许可前取消可阻止写入。获得许可后入库可能已经发生，断线、取消或停服不承诺回滚；合法入库资产可保留，但过期任务不能发布成功状态。界面确认前明确说明此边界。安装结果只保留有界收据和本地资产身份，不在会话内长期持有完整原包；后续可在后台通过服务端所选来源接口重新校验并获取 Selection，读取结束还会复查任务是否仍然有效。不自动加载或放置，也不将本地复用别名视为所选来源。

扩展现有任务 Kind 为 PREVIEW / INSTALL，复用分块结果与完整 SHA 校验，文档严格解析并匹配已下载的收据、authority 和 releaseId 后才显示可确认。摘要不含原始构件包或服务器路径。客户端确认始终由明确按钮动作触发，收到预览不会自动确认。入库工作本身不在服务器主线程扫描或写库；成功后用户可点击刷新按钮，复用既有目录刷新流程。

入库后可通过[所选来源尺寸配方](COMPONENT_COMMUNITY_RECIPES.md)将原件、结果和收据固定到私人收藏；此流程仍不自动加载或放置。

缓存收据代表既往下载校验，不代表当前远端可交付状态；此流程是已下载包的离线本地安装，不自动向远端请求更新。运行兼容性仍未验证。真实游戏交互及多人生命周期需另行联调。
