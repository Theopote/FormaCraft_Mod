# 社区服务配置

服务由服务器管理员按存档配置，客户端不提交 URL。配置位于 `<存档>/formacraft/community/service.json`，缺少文件时保持停用，不创建示例文件，也不自动请求网络。

```json
{
  "schema": "formacraft.community.service.v1",
  "enabled": true,
  "authorityId": "my-community",
  "baseUri": "https://community.example.org/api/"
}
```

此地址仅为占位示例，不代表实际托管服务。baseUri 必须指向实现既有社区 API 的服务根目录；客户端会在目录下请求 `v1/search` 等接口。正式连接仅支持 HTTPS；开发时允许 `http://127.0.0.1:<端口>/` 或 IPv6 数字回环地址。不允许认证信息、查询参数、片段、非规范路径和重定向；不接受代理凭据。authorityId 必须与服务返回的发布身份一致，地址有效不代表发布者或兼容性已获认证。

停用的最简配置：

```json
{"schema":"formacraft.community.service.v1","enabled":false}
```

配置在服务器启动完成时加载；管理员编辑后执行 `/forma_community reload`。`/forma_community status` 查看是否启用及服务身份，不输出地址。`/forma_community disable` 立即取消会话和后台任务、临时停用到下次重载或重启，不改写配置。三个命令均要求权限等级 4，服务器控制台可用。

重载先关闭旧服务，再读取和校验新配置；配置缺失、损坏或初始化失败均保持停用，旧服务不会继续接受请求。有效重载同样使旧会话失效，玩家须重新连接。启动与重载只创建 HTTP 客户端，不探测服务器、不自动搜索或下载。

文件最多 8 KiB，使用严格 UTF-8 / JSON，拒绝重复键、未知字段、类型转换及尾随数据。读取不跟随配置文件及其存档内父目录的符号链接，不接受目录冒充配置文件。不向玩家显示异常原文、服务器路径或配置地址。管理员配置读取为有界本地文件操作；远端搜索与下载仍在已有工作池执行。

本阶段不提供账户、令牌、服务发现、配置 GUI 或公网部署；[入库确认](COMPONENT_COMMUNITY_INSTALL.md) 已接入，下载本身不触发安装。自动测试验证解析、读取边界和命令注册，真实游戏启动、管理员权限和重载断线仍需联调。
