# 平屋顶对宿主体块的覆盖（第十批）

日期：2026-10-04。

第九批只检查屋顶自己的核心范围。本批在全部构件合并后增加宿主检查：对有 component_id 的 MASS_MAIN，关联 host_id 匹配的平屋顶；根体块默认使用宿主 id，附楼使用 host_part_id。编译器推断屋顶时补充缺失的 host_id，已有显式归属保持不变。

按照 ResolvedMassPart 的原点、尺寸、顶面高度建立各体块形状掩码。逐顶面坐标判断：若另一个体块在该位置继续向上占用，则不是暴露顶面；否则必须落在绑定平屋顶的覆盖范围内，且最终仍有非空气方块。覆盖范围包括按 ComponentFootprintMask 允许的合法屋檐外挑。只在 plan 坐标检查，slot 偏移一次。

失败返回 `E_FLAT_ROOF_HOST_COVERAGE`，包含宿主体块 id、首个未覆盖 plan 坐标及数量。屋顶即使自身核心完整，只要太小、水平偏移或形状与主体不符，也会被拒绝。院落和 L 形缺口不要求填充；已发布楼梯净空继续豁免，并由已有通行检查验证。

范围仅为可绑定的平屋顶。旧计划没有组件 id 或屋顶没有 host_id 时不宣称宿主覆盖已验证；没有对应平屋顶的体块不强制补顶，因为可能请求坡顶或其他生成路线。退台/后退外墙暂不执行本检查，避免按底层宽度虚构顶层轮廓。复杂附楼的形状继承、多个组件组成同一建筑、多宿主屋顶、屋面材质和坡顶接缝仍需完善。检查位于地形适应之前，不代表世界放置验收。

回归用例验证：小屋顶自身完整仍被宿主检查拒绝、水平偏移、屋檐合法覆盖、院落孔洞、楼梯开口；既有多体块附楼完整编译样例继续运行。

高低体块遮挡回归：4×4 低体块的顶面被 2×2 高体块遮挡时，只要求其余 12 个暴露位置；删除其中一个暴露位置会准确返回已应用 slot 偏移的 plan 坐标。

验证：`gradlew.bat build --offline` 成功，Java 536 项测试通过；架构检查 20 项已知债务、0 新增。已有源码 jar 重映射警告仍存在，运行模组 jar 构建成功。本批未修改 Python 后端。
