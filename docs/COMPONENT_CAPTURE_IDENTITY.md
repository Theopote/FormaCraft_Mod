# 捕获保存接入内容身份

捕获面板现有保存按钮与网络协议保持不变，服务端将请求视为新捕获记录，不允许客户端指定覆盖目标。服务端保存上下文仍由真实玩家 UUID、独立服务器状态和 OP 权限产生。

新增 ComponentCapturePersistence：在副本上补齐语义并应用现有自动修复，保留作者变体规则；服务器设置 CAPTURED 来源、移除外部原型引用，固定包内临时 ID 为 capture。使用玩家 UUID 构造本地来源命名空间，许可和训练授权均保持未指定，不能把上传者身份当作原作者认证。

构件在内存中经过与离线包相同的结构、大小和环境校验，然后进入 importPackage 共用的锁内事务。相同捕获重用已有资产；改名只追加来源，首次名称不变；同名不同内容生成不同隐藏 ID。旧平面库保持兼容，不按名称覆盖或迁移。

依赖声明只记录实际使用的非原版方块命名空间。命名空间与已安装模组 ID 一致时可直接解析；不一致时服务 API 需要可信的显式 namespaceOwners 映射，不能猜测所属模组。无法确定依赖时在写盘前失败，当前游戏保存入口尚未提供映射编辑界面。

保存 ACK 返回实际资产 ID、实际展示名称和新建/复用/补充来源状态。客户端按服务端 ID 高亮；成功回包缺少有效 ID 时不根据名称猜测身份。新记录才写入缩略图；复用不覆盖原缩略图。目录读取为已安装资产提供已有缩略图路径。

本阶段不提供文件选择导入界面、来源管理界面或旧资产迁移，不写世界方块，不调用会创建外部原型文件的旧保存桥接。
