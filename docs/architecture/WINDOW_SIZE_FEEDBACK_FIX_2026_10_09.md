# 2×2 窗户与入口两侧开窗反馈修复

游戏日志中计划已包含 window_width=2、window_height=2 和 wall=front / left_right，但窗生成器忽略尺寸，编译对齐又把宿主 gable_windows=false 扩展成整个山墙方向的禁窗。

新增 SizedFacadeWindows：明确窗尺寸优先于风格默认节奏，完整矩形窗在每层窗台上生成，留墙角和中央入口区域，按墙厚挖通内层。
wall=front 仅生成入口墙面，left_right 生成与入口方向垂直的两侧；无明确尺寸继续使用既有风格节奏。
编译对齐对单独明确 wall=front 的构件保留正面开窗，不把宿主的宽泛山墙禁窗强加到该构件；未明确正面要求的构件继续遵守原禁窗规则。屋顶山墙本身仍使用封闭构造。

回归测试验证实际玻璃连通区域都是 2×2、入口两侧同时有窗、两层高度、四个入口朝向，以及两格厚墙的内层挖空。全量回归发现并修正了短层高顶层窗被多余顶部边界省略的问题，旧两层总高 6 格的案例仍保留两层完整窗口。

限制：本批未实现 count_per_side/window_per_wall 数量约束、独立层级窗的逐层归属及所有方位 wall 别名；当前按宿主楼层重复规则窗。空间不足时不压缩明确窗尺寸，不宣称已经满足窗数量。
之前给出的“入口两侧开窗，前后山墙不开窗”提示词确有歧义。验收应写为“入口所在墙面两侧开窗；仅屋顶下的三角形山墙区域不开窗”，避免整面墙的开窗要求互相冲突。
