# 风格研究入口与规格第一批

本批修改 Python 后端，无 Java/JAR 改动。重启后端加载。

已实现：独立于地标身份识别的显式风格研究入口；分类器与查询规划器共享判断；未知中文风格、英文 style 表达和引号内原文名称可以保留。已知别名也允许检索补充特征。编辑请求跳过，关闭研究模式仍有效；named_only 模式继续限制普通风格请求。

BuildingProfile 新增可选 style_specs，兼容旧 identity.style：名称、规范身份、地域、时期、用途、作用域，以及逐项特征的来源 URL、可信度和实现状态。搜索 URL 提供给归纳模型，提示要求只引用已提供来源。无结构化归纳时只保留识别名称，不编造地域、特征或来源；作用域未绑定时标为 unspecified。

当前限制：这是研究与数据入口，不是专属几何生成完成。词法提取覆盖有限，并不保证所有语言、所有无风格标记表达都能识别；网络搜索需现有配置。来源真实性尚未进行独立正文核验，LLM 提供的字段仍需后续证据验证。逐特征编译、混合风格作用域绑定和缓存仍待实现。

下一批先把 style_specs 的特征与受支持生成器参数建立可验证映射，并加来源白名单校验；不依靠额外硬编码风格名字宣称覆盖。
