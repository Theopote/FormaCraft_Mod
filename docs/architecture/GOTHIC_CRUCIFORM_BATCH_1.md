# 哥特式教堂十字形平面第一批

## 已实现
- `planVariant=basilica` 保持原长方形中殿与侧廊；`cruciform` 增加突出横厅。
- 总宽包含两端横厅；纵向主体收窄8格，横厅位于纵深约三分之一处，入口仍在另一端。
- 地板与地基按两个矩形的并集生成，不铺满外接矩形。
- 横厅与中殿保持连通，交叉屋顶取两个坡面的较高包络，封闭台阶缝隙。
- 入口朝向、双塔、玫瑰窗、扶壁开关保留。支持中文十字形/十字型、设置/增加/带有横厅以及英文cruciform；总宽至少25格。

## 验证与边界
Java最终方块测试覆盖25、35格与四种朝向，检查轮廓、横厅地板、内部连通以及逐列屋顶覆盖；Python检查路由与总尺寸。
这仍是简化教堂组合，不包含独立唱诗席、后殿、肋拱及复杂窗花；屋顶交叉目前使用实体阶梯封闭，尚非精细的交叉拱顶。游戏外观仍需验收。

## 验收提示词
生成一座哥特式教堂，采用十字形平面，设置突出横厅。建筑总宽35格、深45格，中殿墙高16格，入口朝南。使用默认石材和彩色玻璃。不要双塔，不要飞扶壁，保留玫瑰窗。

检查横厅两端突出、地基不铺成整块长方形、中殿与横厅内部连通、屋顶无空洞。下一批推进唱诗席与后殿，并继续改善交叉屋顶和教堂立面。
