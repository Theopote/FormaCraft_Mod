# 哥特式薄拱顶壳体第一批

新增独立开关 includeVaultShell，默认 false。用户可要求“设置薄拱顶壳体”或“取消拱顶壳体”。只绑定唯一且无局部指向的哥特式建筑。

中殿采用横向尖拱的阶梯壳面，交叉部使用两个相交剖面的包络，后殿在裁切后补入壳面。壳体只封闭顶部及相邻阶梯的高度差；保留壳下通路和壳上屋顶空腔。先生成壳面，再生成装饰肋拱，防止覆盖肋的材料。交叉壳独立启用时仍有四支柱。

这是方块化壳面，不等同于历史曲面或真实结构分析。大尺度壳面高度沿用当前五格拱起，完整比例体系与地域变体仍待完善；环廊、小礼拜堂群和完整礼仪空间也仍未完成。

验收提示：生成一座哥特式教堂，十字形平面，总宽35格、深45格，中殿墙高16格，入口朝南，设置折角后殿，设置唱诗席，设置室内肋拱，设置薄拱顶壳体，保留入口大台阶，不要双塔。

从室内检查中殿和交叉部顶面是否连贯、装饰肋是否仍可辨认、中央通道是否通畅；飞入屋顶检查壳体与坡屋顶之间仍为空腔。对照取消拱顶壳体时，应恢复已有开放骨架。未打包 JAR。
