# 屋顶最终补丁形态审计第一批

接入 ComponentPlanCompiler 的后处理完成阶段，检查最终方块补丁而不是只查看 roof_type 字符串。已有平顶覆盖和宿主覆盖检查继续保留；新增简单矩形双坡屋顶剖面审计。

审计遵循最后一次补丁操作，识别删除/空气；包含布局槽位偏移。读取屋顶中段横剖面的最高实体方块，检查两侧向屋脊的上升、屋脊高于两边和坡面列完整。日志 [RoofShapeAudit] 给出 componentId、matched / mismatch / not_assessed、原因与剖面高度。

本批是非阻断诊断，不改变生成几何，不将复杂屋顶误拒绝。带老虎窗、双檐、非矩形及过小占地不宣称已验收。检查范围仅是中段剖面，不证明整个坡面、材质、室内净空或最终世界落地后状态均正确；地形落地仍需单独验收。

回归：真实双坡生成器在两个屋脊方向与多个屋檐伸出量通过；强行压平、删除坡面列能够报告问题；布局偏移正确，复杂屋顶未评估。下一批扩展多剖面覆盖与宿主连接，再检查玻璃材质、通透门窗和室内空间。

本批修改 Java 模组，需更换 build/libs/formacraft-1.0.0.jar 并重启游戏。
