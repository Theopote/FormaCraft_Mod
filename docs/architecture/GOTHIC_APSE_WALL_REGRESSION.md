# 后殿启用后十字形教堂缺墙回归

## 日志证据

run/logs/latest.log 的 16:16:34–16:16:56 记录：原生 gothic_cathedral_hall，planVariant=cruciform，includeApse/includeChoir/includeRibVault=true，总宽35深45。编译、落地、预览确认与建造均完成；最终计划61917方块、放置8722、相同跳过53195。没有任务中断的证据，不能单以放置率判断几何完整。

## 原因与修复

十字形内部调用 basilica 子厅时继承了 includeApse=true，提前清除了后端角点。横厅材料随后从子厅 (0,4,0) 取出 AIR，横厅墙体被生成为空气。外层后殿又从受影响的位置取材，扩大了缺墙范围。

内部子厅显式关闭后殿和唱诗席，只在完整十字形建筑合成后执行一次后端修改。墙体取材点同时增加非空且非 AIR 校验，避免悄悄产生空气墙。

此前测试只查地板、屋顶和通路，没有查外墙连续性，这是漏检。本次补查四朝向下后殿后墙、横厅两端和侧墙最终写入，玻璃允许但 AIR 不允许。保留已有中心锚点、台阶、屋顶空腔及中殿通行测试。未打包 JAR。
