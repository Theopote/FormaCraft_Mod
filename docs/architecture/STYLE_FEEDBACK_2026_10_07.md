# 2026-10-07 游戏反馈修复

来源：`run/logs/latest.log` 中21:51至22:01的六次编排响应，保存为 `src/test/resources/style_log_cases_round5`。文件编号为日志响应顺序，包含重复尝试，不等于提示词编号。

## 材料失败

现代住宅的 `DECOR_DETAIL` 同时有 `wall_block=minecraft:white_concrete` 与 `material=concrete`。装饰生成器以前直接把通用材料名拼成方块ID，产出不存在的 `minecraft:concrete`。现在优先读取明确的 block/trim_block/wall_block，通用材料通过现有材料解析器转换；真正未知的ID仍由原有验证拒绝。

## 山墙窗户

日志中“只保留普通封闭山墙”没有形成禁窗参数。契约观察新增 `gable_windows=false`，按建筑作用域绑定到主体。编译器将禁窗方向传入显式与自动立面；主体自带窗户同样跳过山墙平面。不会把山墙禁窗误判为整栋禁窗，其他侧墙继续允许窗户。

当前方向采用已有双坡屋顶规则：屋脊沿占地长边，山墙位于长边两端。自定义屋脊轴向的支持仍需后续统一处理。

## 高低不一的石砖圈

除编排方案的地基和檐口组件外，默认细节后处理还会在整个方案占地外缘逐列查找最高方块并加装饰。外缘含地基、檐口或偏移构件时，最高方块的高度不同，额外圈便落在不同高度；这不是建筑整体落地平移能修复的问题。

移除这种隐式檐口加圈。明确编排的装饰构件仍沿原来的宿主绑定路径生成，不再靠全局最高列推断屋顶边缘。保留已有角柱、腰线替换及材料保护逻辑。

新增回归验证具体材料优先、通用混凝土解析、不在地基/屋顶混合列添加新圈、山墙方向禁窗而侧墙仍有窗，以及六份真实日志方案契约归一化的幂等性。旧回归的“允许装饰必须出现新圈”假设同步改为不添加隐式圈。
