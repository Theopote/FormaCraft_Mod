# 哥特式中殿内部骨架第一批

本批按风格与类型能力矩阵继续补教堂内部空间。`includeRibVault=true` 启用成对柱与横向尖拱肋骨架，默认关闭；柱与飞扶壁采用相同开间边界，尖拱顶部位于中殿墙顶之下，地面中央通路保持开放。

这是方块化内部骨架，不是完整历史肋拱体系：没有拱顶壳体、对角肋、交叉部拱顶。十字形生成器会清除横厅交叉范围的骨架，保留已验收的交叉空间净空。唱诗席/后殿尚未实现，不将骨架等同于完整风格支持。

用户可说“设置室内肋拱”或“取消室内肋拱”；仅在唯一哥特式建筑且无局部建筑指向时绑定参数。取消优先于同时出现的启用表述。

验收提示词：

> 生成一座哥特式教堂，宽35格、深45格，中殿墙高16格，入口朝南，设置室内肋拱，不要双塔，保留飞扶壁和玫瑰窗。

检查中殿两侧柱是否接地、柱顶尖拱是否连接、拱下与不同开间间是否为空；入口至中殿中央能连续行走。然后将“设置室内肋拱”换为“取消室内肋拱”对照。十字形版本的交叉部目前保持开放，无专用交叉肋拱。

自动验证覆盖四朝向、启用/取消、柱连续支撑、拱顶存在、中央净空与无实体拱顶填充；Python 覆盖语言启用、取消、冲突和范围。未打包 JAR。
