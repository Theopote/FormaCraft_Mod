# 建筑细化阶段的构件身份保留

修复原因：plan_architectural_enrichment 原来用 roof_spec 整块替换已有屋顶 params。最终建筑契约因此重新分配屋顶 ID，研究特征的 roof_a 目标失效，装饰的 attachment_host_id 也可能成为悬空引用。

本批保留既有屋顶的 component_id、host_id、附件元数据、材料、明确禁用项、屋顶类型以及原有特征。细化生成的缺省参数只补缺；原有顶层元数据和 slot_id 保留。新生成的构件在主体身份存在时明确标注宿主，并继承主体 slot_id，由最终契约分配新 ID。

该旧细化器只知道如何调整一个主体及其屋顶，现在对多体量、多屋顶或屋顶引用其他宿主的计划跳过，避免将第一栋的尺寸与全局风格套到另一栋。此举不删除已有构件；多栋建筑的专属细化仍需后续按宿主实现。

验证包含：单栋细化前后身份和附件引用、材料及禁用项保留、新构件宿主/槽位、多体量与多屋顶不误改，以及最终规范化后研究特征仍准确绑定原屋顶 ID。当前仍为计划层验证，没有游戏方块造型验收。

部署：仅 Python 后端改动，重启后端加载，无需更换模组 JAR。
