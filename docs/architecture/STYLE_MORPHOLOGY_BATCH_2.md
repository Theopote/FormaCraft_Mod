# 徽派马头墙：第二批

Component屋顶生成路径新增阶梯式封火山墙。徽派硬山顶默认启用 `horse_head_walls`，已有显式值优先；其他屋顶不自动启用。参数也接受 `horseHeadWalls`。生成器仅在单檐双坡、封闭山墙、完整矩形且短边至少5格时生成，复杂庭院与异形屋顶留待分段山墙规则。

两端墙体保持一格厚，阶梯顶部高于对应屋面1至2格；墙材继承 `wall_block` 或当前墙面材料，压顶继承屋顶材料。构件保持在主体端面范围内，不添加悬空的外侧构件，也不填阁楼。明确 `horse_head_walls=false`、`gable_walls=false`、无复杂装饰或无屋顶均会停止生成。

游戏测试：

1. 生成徽派一层小住宅，宽11格深9格，室内净高4格，矩形占地，白色混凝土外墙，深板岩瓦硬山双坡顶，两端设置马头墙，墙厚和楼板厚均1格，室内中空，入口两侧设窗。
2. 同样生成徽派小住宅，宽11格深9格，白墙黑瓦硬山双坡顶，但不要马头墙，不要复杂装饰，保持普通封闭山墙和中空阁楼。
3. 生成徽派风格一层住宅，宽11格深9格，白墙，用户指定平屋顶，不设置马头墙，墙厚1格，室内中空。

观察两端轮廓是否对称、压顶是否连续接触墙体、阁楼是否中空；第二与第三条是否保留关闭要求。自然语言到参数的规划结果仍需游戏日志验收，本批不宣称完整徽派构件体系已完成。
