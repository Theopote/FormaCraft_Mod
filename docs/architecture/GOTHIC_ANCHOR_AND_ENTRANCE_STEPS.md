# 教堂底面中心锚点与入口大台阶

教堂原生生成默认将传入锚点作为主体底面中心，按入口朝向旋转中心到角点的偏移；十字形内部递归显式使用 corner，避免重复居中。地形规划采用相同换算。保留 anchorMode=corner / bottom_left 兼容内部角点调用；用户通用单教堂路由固定 center。台阶、屋檐等附属构件不参与主体中心计算。

默认入口台阶：宽度随中殿宽度取 9–13 格，门外地板标高平台与三层向外下降的石砖台阶，台阶下实体承托、上方清空。includeEntranceSteps=false 或“不要入口大台阶”可关闭。地形高差额外连接仍由落地规划处理，不将固定三层台阶等同于所有高差均能直接到达自然地面。

现有普通房屋本身已有中心锚点处理；本批修复原生哥特式教堂及其落地范围，未批量改变桥梁、道路等非建筑生成器的坐标契约。

验收：以鼠标选择一个清楚的地面点，生成总宽35格、深45格、入口朝南的十字形哥特式教堂，设置室内肋拱，保留入口大台阶。该点应在主体底面中心，门前有宽平台与连续台阶。分别换入口朝东、北、西，并对照“不要入口大台阶”。本批不打包 JAR。
