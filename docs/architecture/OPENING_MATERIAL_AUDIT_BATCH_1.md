# 门窗实际方块审计：第一批

## 实现

独立 FACADE_WINDOWS 现在通过 GeneratedSurfaceCapture 记录实际窗口表面，参与已有声明表面完整性检查和后处理表面保护。
编译器按生成顺序保存明确材质的 WINDOW 与 DOOR_OPENING 期待，应用各自槽位偏移；后续声明的表面角色覆盖先前期待。

后处理结束后输出 `[OpeningMaterialAudit]`。明确指定的 glass_block / glazing_block / glass_material / window_block 以及独立窗构件的玻璃或铁栅栏 material / block，按方块 ID 与最终后写覆盖结果比较。
窗口材质改变或删除记为 window_material_changed。入口允许 air、REMOVE 与 door 方块，其他占据记为 door_opening_blocked。
没有最终补丁的坐标视为未评估，不把它当作已确认空气。

## 验证与限制

测试涵盖实际独立窗生成器、徽派下明确玻璃、槽位偏移、铁栅栏替换与恢复、入口门方块/空气/封堵、后续角色覆盖及未指定材质。
新增材质和入口审计只写日志，不拒绝生成；已有声明表面完整性检查仍照常工作。
方块属性不参与材质 ID 比较；door 后缀允许正常原版与模组门，但不验证开门条件、完整上下门扇或实际碰撞形状。
仅检查生成器记录的坐标，尚不证明缺失窗数量、窗口尺寸、整个墙厚的通路或用户文字被正确解析。
不读取世界地形落地状态，不对未指定材质推测玻璃期待。
未记录表面角色的生成器和后加装饰仍属于覆盖范围外。

下一步应补充入口厚墙净空与最终世界落地诊断，并将用户要求、构件期待和最终方块结果对应起来。
