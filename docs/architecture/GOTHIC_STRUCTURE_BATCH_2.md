# 哥特式结构第二批：飞扶壁与塔型

- 飞扶壁采用离散上升拱曲线，跨越侧廊上方，连接从底面起的支墩与中殿墙；保留拱下空气。仍是方块化近似，非结构力学求解或完整历史拱线。
- towerArrangement支持none/single/twin。single目前固定在正面左侧，不支持任意位置或交叉塔。includeTowers=false仍可直接禁用全部塔。
- 尖顶收缩速度按spireHeight计算，消除小塔宽导致尖顶提前终止的问题。塔顶封盖、尖顶中央支撑与端部闭合保证连续。towerHeight表示塔身高度，spireHeight表示额外尖顶高度，顶端还有一格封顶。
- “不要双塔，设置单塔”按替代方案启用单塔，不误解成所有塔禁用。明确“无塔”走无塔配置。支持“塔身高N格、尖顶高N格”数字参数。
- 保留窗位、三角端墙、屋顶空腔和地基落地规则。横厅范围不保留穿入室内的纵向扶壁。

验证最终方块中塔型、6/10/20格尖顶连续高度、入口净空、支墩接地、拱两端接触和拱下空气。只运行测试，不打包JAR。

验收提示词：生成一座哥特式教堂，十字形平面，总宽35格、深45格，中殿墙高16格，入口朝南。不要双塔，设置单塔，塔身高24格、尖顶高14格，保留飞扶壁和玫瑰窗。

侧面检查扶壁承托，正面检查仅左侧塔和尖顶。复杂飞扶壁、小尖塔、塔冠窗与交叉塔仍未完成；下一步推进塔楼立面或唱诗席/后殿组合。
