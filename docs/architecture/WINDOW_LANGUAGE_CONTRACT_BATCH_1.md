# 窗户数量与楼层语言契约：第一批

后端 apply_building_contract 在构件身份和宿主处理后绑定保守的中文模板：
- 入口两侧各两扇窗 → front 的 count_per_side=2。
- 每面侧墙每层三扇窗 → left_right 的 window_per_wall=3。
- 只在二楼开窗 → 宿主明确的独立窗构件 window_floors=[2]。
- 正面只在二楼开窗 → 仅 front 绑定楼层过滤，不改变侧墙。

生成端在完整矩形和原有风格节奏路径均按宿主局部高度过滤楼层，楼层序号从 1 开始。
proportion_hints.window_language_report 记录原文、目标构件和计划级状态，不宣称最终方块验收完成。
找不到明确墙面绑定、数量冲突、未支持的建筑范围或单层特定数量报告未解析，不擅自扩大范围、不新增几何构件。
支持数字及一至十的简单中文数词，不支持全部自然语言变体；每层不同数量、命名建筑分配、楼层范围和英文模板尚未覆盖。
只有 floor 过滤并不代表所有其他生成器的内嵌窗已过滤；本批以已有 FACADE_WINDOWS 的独立窗主路径为范围。

部署需要更新模组 JAR、重启游戏及后端进程，以加载新语言契约模块。
