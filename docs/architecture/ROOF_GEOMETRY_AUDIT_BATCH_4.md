# 屋顶方块形态审计：第四批（纵向整段偏移）

在已有横向剖面检查后，比较相邻内部剖面的全部柱顶高度。
若整个剖面以相同非零高度差平移，记录 longitudinal_section_shift，并给出异常剖面索引。
这补足了“各剖面分别符合双坡，但一整段上下错位”的检查空缺。

验证包含两个屋脊方向、上移及下移的段间变化、偶数跨度和挑檐正常屋顶，以及整体屋顶连同槽位一致平移的合法情况。

仍为编译后处理补丁上的非阻断日志诊断。仅识别整剖面一致平移，不宣称检测全部纵向损坏；单列凸起、烟囱遮挡、屋面内洞及实际世界落地未覆盖。
复杂屋顶沿用现有 not_assessed 规则。刻意设计的整段高差也可能触发诊断，应结合用户要求解读；不能将此规则直接作为通用建造拒绝条件。
