# 后殿多面屋顶与交叉肋拱

后殿屋顶采用后坡与两侧坡高度的较低值形成相交屋面：后端从檐高逐排升高，在第六排接至已有中殿屋脊。相邻屋面高度差用薄竖向台阶封缝，不填满屋顶内部。沿用主体屋顶材质、总宽深及中心锚点。

十字形开启 includeRibVault 时，在交叉部生成四根接地支柱和两条对角尖拱肋。肋位于屋顶下方，中央纵横通路保持净空。取消室内肋拱同时取消中殿及交叉部骨架。

本批不是完整拱顶壳体，也不模拟真实结构受力。缺口仍包括薄拱顶壳体、环廊、小礼拜堂群和完整礼仪布局。新增自动检查涵盖四朝向、后坡降低、屋脊接缝、空腔、交叉肋顶点和四支柱、开关及横向通行；保留缺墙回归。

验收沿用：生成一座哥特式教堂，十字形平面，总宽35格、深45格，中殿墙高16格，入口朝南，设置折角后殿，设置唱诗席，设置室内肋拱，保留入口大台阶，不要双塔。

重点看入口对面后殿屋顶是否有向后下降的坡面；室内交叉部是否有对角肋拱、是否能从下方穿过。未打包 JAR。
