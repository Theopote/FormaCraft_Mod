# 屋顶方块形态审计：第二批

## 本轮实现

- 简单矩形双坡屋顶从中段一个剖面扩展到全部内部剖面，两个屋脊方向均适用。
- 每个剖面检查缺失列、中心屋脊高于两侧，以及向屋脊上升、远离屋脊下降的单调形态。
- 日志保留异常剖面高度，并增加 sectionIndex（沿屋脊方向、从 0 开始）与 checkedSections。
- 最终方块先按坐标处理后写覆盖，再建立柱顶索引；删除与后续恢复均正确反映在结果中。
- 回归测试覆盖非中段缺口、两个方向、删除后恢复和全部内部剖面计数。

## 验收范围与限制

审计仍为日志诊断，不拒绝生成。它读取编译后处理后的方块补丁，不读取实际世界落地结果。
两个端面不参与剖面审计，以免山墙装饰被误判。老虎窗、双檐、非矩形屋顶仍标记未评估。
柱顶形态不是完整屋面验收：柱顶下方的空洞、叠加构件遮挡缺口、纵向高度突变及屋顶与墙体的实体接缝尚未验证。
既有平顶宿主连接校验仍保留；本轮未把其高度约定直接推广为双坡屋顶硬性约束。

## 下一步

建立屋顶与宿主的明确接缝期待，区分山墙、檐口、子建筑体和样式装饰，再检查最终方块的连接。
复杂形态应独立标记覆盖范围，不能凭参数名宣称几何已通过。
