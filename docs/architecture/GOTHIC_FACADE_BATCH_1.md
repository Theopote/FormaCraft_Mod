# 哥特式立面第一批：开间、尖拱窗与门框

## 实际实现
- 与现有扶壁共用buttressStep：扶壁在开间边界，窗在中心；前双塔占据的末端区间不布置被塔吞掉的窗。
- 侧廊为离散尖拱双联窗，下部中央窗梃分开两片玻璃，上部保留简化玻璃眼与收窄尖顶。宽开间允许较宽窗口；不是历史曲线的精确复刻。
- 高侧窗受可用净高限制采用简化尖拱，横厅端部采用较高较宽的同类窗口，朝向旋转一致。
- 门洞顶端尖拱实际开口，墙面与外凸一格的石框提供深度；没有生成多重复杂雕花门廊。
- includeWindowTracery=false去除中央窗梃，保留玻璃；includeWindows=false禁用普通立面窗，玫瑰窗由独立开关控制。中文“不要窗花”接入单栋原生契约；“整座建筑不设窗户”同时关闭普通窗与玫瑰窗，避免违背全局禁窗。
- 局部立面无窗不自动推广到整座建筑；尚未加入完整的逐立面原生窗覆盖契约。

## 验证
检查最终写入方块：左右玻璃、下部窗梃、顶部尖拱收窄、扶壁边界没有玻璃、入口尖端空气与框深度，覆盖4/5/7/8格开间与四朝向。原有屋顶、侧廊封墙、地基落地测试保留。
仅运行test，未打包JAR。窗花目前是最简组合，并非火焰式复杂窗花或放射玫瑰窗完整实现。

## 验收提示词
生成一座哥特式教堂，采用十字形平面，设置突出横厅。建筑总宽35格、深45格，中殿墙高16格，入口朝南。不要双塔，不要飞扶壁，保留玫瑰窗。

先观察侧廊窗和横厅端窗的尖拱、中央窗梃、上部玻璃，再观察门框厚度与入口通行。同一提示增加“不要窗花”比较玻璃窗保留情况。

下一批重点是飞扶壁的拱形与承托关系、塔型配置；唱诗席、后殿、室内柱列及肋拱仍待实现。
