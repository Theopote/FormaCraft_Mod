# 哥特式教堂唱诗席与折角后殿第一批

## 实现边界

includeApse=true：在主体后端前六排内生成对称收窄的折角终端，基础与地板随平面收窄，外墙封闭，顶部为裁切的坡顶壳体。中殿中央与终端内侧相通。保持原有总宽、总深与中心锚点；不是向原尺寸外追加空间。默认关闭，保留已验收方案。

includeChoir=true：后端两侧放置两排面向中央的木座席，中央至少三格通道留空。只是简化座席，不等于完整礼仪空间、唱诗席屏障或独立祭坛体系。

支持“设置折角后殿”“设置唱诗席”及对应取消；只绑定唯一且无局部建筑指向的哥特式目标。任意半圆后殿、环廊、小礼拜堂群及地标仍不由通用路由自动替代。

本批屋顶沿已有中殿坡度裁切，不是精细放射状多面后殿屋面；内部无实体填充。折角终端每个占用柱有地板、屋顶，外壳与中殿连续。小尺度后墙省略尖拱窗以避免窗框超出狭窄墙面。

## 验收提示

> 生成一座哥特式教堂，十字形平面，总宽35格、深45格，中殿墙高16格，入口朝南，设置折角后殿，设置唱诗席，设置室内肋拱，保留入口大台阶，不要双塔。

查看入口对面的后端是否对称收窄、后墙是否封闭、屋顶是否完整，中殿能否走到后殿、座席是否分布在通道两侧。再以“不要后殿，取消唱诗席”对照。四朝向与 basilica/cruciform 均有方块最终写入验证。未打包 JAR。
