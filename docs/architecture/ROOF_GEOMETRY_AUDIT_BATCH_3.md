# 屋顶方块形态审计：第三批（边界接缝）

## 实现

新增 RoofSeamAudit，编译后处理完成后输出 `[RoofSeamAudit]` 日志，不改变生成和拒绝规则。

明确 host_id、host_part_id 绑定的 MASS_MAIN 建筑体通过 ResolvedMassPart 解析坐标，分别叠加宿主与屋顶的槽位偏移。
仅审计矩形、与宿主占地一致、无挑檐、无特殊特征的 flat / gable / double_gable 屋顶。
宿主顶部有进退变化或空缺、开放山墙、双檐、老虎窗等构造标记 not_assessed；无宿主及宿主身份不唯一也不宣称通过。

附着高度允许屋顶基面与宿主最高层重叠，或位于其上相邻一层；超出该范围记录 vertical_alignment。
读取最终补丁的后写覆盖结果，在周界检查屋顶基面与紧邻下层的占据情况。
缺失时输出 firstMissing、missingCells、checkedCells；恢复放置会覆盖先前 REMOVE。

## 验证

回归测试使用实际 RoofGenerator 屋顶和中空墙壳，覆盖平顶、双坡、两种附着高度、墙顶删除后恢复、悬空高度、独立槽位与开放山墙/挑檐排除。

## 范围限制

本审计检查编译结果，不检查地形落地后世界状态；占据不代表材料或力学正确。
接缝环的占据不能证明方块来自指定屋顶或墙体；重叠建筑可能遮住缺口。
开放式亭廊、挑檐、复杂屋顶与不一致占地需要独立接缝模型。
若用户明确要求顶层开放的立面，当前非阻断诊断仍可能提示缺口，应结合构件语义解释。

下一步应依据构件表面归属与开放边界建立接缝期待，再扩展挑檐和开放构造；不能直接把当前边界环规则作为所有建筑的硬性要求。
