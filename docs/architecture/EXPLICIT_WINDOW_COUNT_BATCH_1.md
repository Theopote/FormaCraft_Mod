# 明确窗户数量：第一批

SizedFacadeWindows 接入 window_per_wall / windows_per_wall / windows_per_floor，每个被选中的墙面按此数量逐层生成。
入口墙面若保留中央入口，数量在左右两侧分配；count_per_side 指定入口每侧数量，其优先级高于入口墙面总数。
零数量明确禁止该构件开窗。仅有数量而没有尺寸时，也启用明确布局，使用默认 1×2 窗；没有数量时保持原来的默认间隔算法。

完整窗口留在墙角边界内，明确数量布局至少保留一格窗间墙体；能容纳时均匀分布，尺寸保持不变。
要求数量超过可容纳数量时，日志输出 [WindowCountLayout] requested/fitted/interval/windowWidth，并生成可容纳的完整窗口，暂不拒绝整栋生成。

测试覆盖侧墙每层三窗、入口每侧两窗、零窗、过密要求下的完整矩形和墙角保护。

限制：windows_per_floor 在这里是各选定立面每层数量，不是整栋跨立面的合计；应由计划层明确范围，不能把未消歧的整栋总数直接下传。
本批不新增自然语言数量解析、不验证最终世界窗数量，日志尚未转换为用户可见的保真度提示。入口两侧空间不对称时，固定左右分配可能留出未使用容量，后续应做受约束的再分配。
