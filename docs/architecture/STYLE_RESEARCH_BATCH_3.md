# 风格特征作用域绑定与参数验收

本批 Python 后端已接入最终计划处理：建筑契约与建筑细化完成之后，根据最终构件 ID、建筑 ID、requirement_scope 和宿主关系绑定研究缺省。

规则：只支持当前精确的平顶/双坡映射；只有一个候选屋顶且宿主唯一才能执行。未指定范围只在候选唯一时绑定，多栋/多屋顶不按数组顺序推断。建筑范围与构件范围取交集；重复 ID、缺失宿主、缺失目标、相互冲突的缺省分别报告。已有屋顶参数（含宿主继承参数）保留；用户硬要求优先，未解析用户作用域阻止套用。

仅填补缺失的 roof_type，不创建屋顶、不改变尺寸坐标。最终 proportion_hints.style_feature_report 保存 schema、状态、目标与参数比对，日志同步记录。applied_default / matched_existing 仅说明计划参数对应，不代表方块形态验收。报告不会导致原本可以生成的建筑被拒绝。

限制：建筑细化可能重建屋顶并更换构件 ID；针对旧屋顶 ID 的特征会报告 missing_target，不猜测继任者。作用域与模型字段仍需今后从自然语言更准确地绑定。已有计划参数冲突目前报告并保留，未做自动修复。用户约束的识别范围沿用建筑契约，尚不是所有语言的完整理解。

下一步建议：稳定细化前后构件身份，再扩展可执行特征；建立最终方块几何验收，避免仅根据文字或计划参数宣称风格落地。
