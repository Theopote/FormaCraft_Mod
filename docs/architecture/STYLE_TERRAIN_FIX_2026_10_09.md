# 2026-10-09 玻璃窗及屋檐圆石支撑修复

游戏日志确认混合风格住宅的窗户构件明确 material=minecraft:glass，但 FacadeWindowsGenerator 忽略这个参数，随后徽派材质表选用了 iron_bars。本批显式 window_block/block/material 中的玻璃或铁栏材质优先于风格缺省。Python 建筑契约新增玻璃窗材质要求，按宿主将 glass_block 传递给主体和独立窗户，主体生成器亦优先采用 glass_block。

BuildingLandingPlanner 原来按每个非空气列最低点向下支撑，包括只有屋檐的外围列。当邻近地形较高时，这些列填到屋檐下，形成圆石墙帘。本批只有最低点不高于主体基底的列才可填支撑；屋檐列仍参与必要清理，不再成为地基承重点。原有基础支撑及削坡保留。

回归：新增徽派显式玻璃优先测试、靠高地的屋檐不产生高位圆石测试及双栋玻璃要求绑定测试；Gradle build --offline 成功，相关 Python 50 项通过。

需更新 build/libs/formacraft-1.0.0.jar，并重启后端及游戏。原有世界中的旧圆石和铁栏不会由此次代码修改自动清除，请重新生成验收。第四条原提示前后山墙不开窗，东侧山墙无窗符合要求；侧墙玻璃及入口仍需复测。尚未进行游戏视觉验收。
