# 现代与徽派形态规则：第一批

本批作用于 ComponentPlanCompiler 的组件风格默认解析路径，不改用户指定尺寸，也不自动把住宅改成其他用途。

| 条件 | 默认行为 |
|---|---|
| 现代国际主义，未指定屋顶 | 平屋顶；默认普通玻璃窗风格 |
| 徽派，未指定屋顶 | 硬山双坡顶；复用已有山墙封闭逻辑 |
| 徽派，占地任一边小于14格 | 保持矩形主体，不默认切角，不添加庭院特征 |
| 徽派，两边均至少14格，未指定平面 | 延续已有庭院平面默认 |
| 显式指定屋顶、平面或窗墙比 | 保留指定值，包括 none 与零窗墙比 |
| extrude_mode=plate | 楼板不接受主体或屋顶风格默认 |
| 明确的现代/徽派身份与装饰词冲突 | 明确身份优先于装饰特征推断 |

新增方块几何回归比较同尺寸屋顶：现代为单层平板；徽派具有双坡高差、封闭山墙和空阁楼，方块均处于指定占地内。附加回归覆盖显式覆盖、小尺度及楼板隔离。

回归同时发现并修复屋顶占地掩码忽略显式 `plan_type=none` 的缺陷；现与主体生成器一致，显式矩形不会被风格重新推断为切角。完整离线构建通过，647项Java测试零失败。本批没有修改Python后端。

本批尚未新增马头墙、天井专用采光组织或部位级混合风格绑定。完整徽派视觉验收需要后续构件规则；Assembly宏路径也仍需独立完善。不要将本批默认规则理解为所有用途的完整风格生成器。

## 游戏测试提示词

每条在新的空地单独测试。前两条故意不指定屋顶，用于观察风格默认；第三条用于检查用户覆盖。

1. 生成一栋现代国际主义风格的一层住宅，宽11格、深9格，室内净高4格。保持矩形占地，墙厚1格，楼板厚1格，室内中空。正面中央为矩形入口，门两侧设置窗户。根据当地地形处理地基。
2. 生成一栋徽派风格的一层小住宅，宽11格、深9格，室内净高4格。墙厚1格，楼板厚1格，室内中空。正面中央为矩形入口，门两侧设置窗户。根据当地地形处理地基。
3. 生成一栋现代国际主义风格的一层住宅，宽11格、深9格，室内净高4格。用户指定云杉木双坡屋顶，矩形占地，石砖外墙，墙厚1格、楼板厚1格，室内中空。保留指定屋顶和材料，正面设置矩形入口与两侧窗户。

观察：前两栋是否有明显屋顶差异；小徽派住宅是否没有意外切角或院洞；第三栋是否保留双坡顶；山墙是否封闭、阁楼是否中空。游戏实际结果仍可能暴露规划阶段提前填入其他默认值的问题，应结合日志中的最终组件参数定位。
