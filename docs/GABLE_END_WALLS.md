# 双坡山墙封口

单层矩形 `gable`、`double_gable`、`xuanshan` 屋顶在主体两端生成山墙。屋脊沿长轴，山墙平面位于屋顶核心尺寸的两端，不沿外挑屋檐向外延伸。墙面从屋顶接合高度生成到已有坡面下方，不覆盖坡面，不填充阁楼内部。

山墙高度读取基础屋面实际输出，排除后加老虎窗与强调屋檐，防止装饰抬高山墙。材料优先使用 `wall_block`，其次使用动态墙面材料与风格调色板。推断屋顶继承主体参数，因此主体明确指定的墙面材料可以继续使用。

新增山墙记录为 WALL，参与生成来源检查和后处理保护，既有开口权限允许墙面开口。坡面仍记录为 ROOF。显式 `gable_walls=false`（布尔值或字符串）关闭封口，可用于开放端面的建筑。

适用边界：本批仅处理完整矩形核心和非重檐双坡屋顶。院落、L 形、圆形等平面不填补其包围盒；重檐、歇山、独立坡顶验收、超陡坡连续性仍待完善。`double_gable` 仍沿用既有双坡几何语义，没有新增交叉屋脊。

实际方块回归覆盖两个屋脊方向、奇偶跨度、非零锚点、外挑屋檐、墙面材质、阁楼保留、表面记录及关闭封口参数。游戏内观感仍需实测。
