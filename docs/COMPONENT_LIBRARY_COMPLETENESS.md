# 构件库完整性复核

## 当前范围

本地资产闭环包括捕获、类型与标签、内容身份、按权限入库、来源、检索与适配、预览和使用、删除、离线包导入导出。按用户要求，社区托管与远端索引暂缓，详细计划见 [社区服务计划](COMPONENT_COMMUNITY_PLAN.md)。本地不可变快照及尺寸配方收藏已继续实现，见 [本地快照与变体收藏](COMPONENT_LOCAL_RECIPES.md)。项目没有旧资产迁移要求。

## 本次发现与实现约束

1. 删除按钮直接调用客户端磁盘，无法操作独立服务器资产。改为服务器执行，按当前可见记录定位唯一安装目录；私人记录只能本人删除，共享记录要求单人服或 OP。请求绑定主来源 contentRef，过期目录拒绝删除，不按同名或跨库批量删除。成功回执后才刷新客户端状态。
2. 包导出只有底层 API，没有游戏入口。补充从当前选中来源导出，分块下载不可变包快照，再由用户选择本地文件；保留原始内容、发布身份与许可，不自动重签名、改授权或发布到网络。文件只新建、不覆盖；取消文件选择不落盘。
3. 库列表仍以客户端全局目录判断服务器目录项存在性，会隐藏远端记录。列表以服务器下发目录为准。
4. 最近加载/标签命中排序对整个组合 comparator 再次 reversed，意外反转主排序。分别对每个降序字段反转，并以 ID 稳定打破同分。
5. 滚动区按钮和网格必须受裁剪区域约束，隐藏控件每帧清除可见状态。
6. 大构件捕获虽已分块上传，原加载消息仍受单字符串限制。已安装资产加载复用分块快照，验证来源后映射本地 ID 和包内原型引用，与服务器运行副本一致；导出保留原始发布载荷。
7. 缩略图只读客户端目录，远端资产无法显示。远端库现在按需下载结构并使用客户端资源包渲染缩略图；后台最多一个下载、队列最多 24 项、图片缓存最多 96 项。主动加载/导出/删除优先，中断后台任务并允许重试；断线清空缓存和工具加载状态。
8. ClientComponentCatalogState 收到目录后还有第二处本地文件过滤，会删除新格式安装资产和远端资产。目录缓存已移除此逻辑，以服务器目录为准；刷新损坏时保留上次有效快照，权威空目录不从磁盘复活，切换连接时清空缓存。远端连接不进行本机目录回填或从本机文件推断插槽原点。
9. 目录自身仍使用单字符串消息，大型库会触发长度限制。改为带递增修订号的 UTF-8 分块快照，收到完整有效快照才替换缓存；新修订替换未完成旧修订，旧包不能覆盖新目录。服务端每玩家每 tick 最多发送两块，接收活跃期间自动重试器不会反复重启传输。

导出会话按玩家绑定，限制单包 16 MiB、分块 20 KiB、总快照 32 MiB、最多 4 位玩家，120 秒超时；必须连续拉取，不接受路径。断线、取消、完成和服务器停止释放快照。删除及导出操作均不修改世界方块。

库入口提供刷新按钮。未查看来源时导出首份，查看某一页来源后导出该页；请求绑定内容引用与 manifest 指纹，避免相同结构、发布者和版本却不同许可的来源互换。客户端完整性检查不要求本机安装服务器全部依赖；这类检查所得快照不能直接入库，安装仍必须进行目标环境验证。来源各自导出，不把多份独立许可拼成一个合成授权。

目录单快照上限 16 MiB、分块 20 KiB，发送队列最多 4 位玩家、总快照 32 MiB。新请求替换该玩家的旧快照；超额返回明确同步失败，原有效目录保留，可刷新重试。接收端 120 秒无活动释放未完成快照，断线两端释放。该容量限制不等于大型社区远端索引方案；按需远端搜索和分页索引仍属于后续服务层。

## 后续产品能力与验收

本地尺寸配方已支持原件快照锁定、收藏、重放校验和离线恢复；此处的“离线”指无需社区网络或仍存在的可见原件，游戏服务器仍需运行且满足原包依赖。后续又接通了使用库资产的 components BUILD 锁清单、最终结构快照和命令预览/恢复，详见 [建筑构件锁与本地复现](BUILDING_ASSET_LOCKS.md)。尚未实现：完整锁包跨世界/跨设备备份格式、与已建成 ProjectMemory 的绑定及增量锁更新、镜像/换材等更丰富的收藏参数、任意变化区域涂选与独立净空编辑、示例宿主上的交互安装试验、材质变化后的风格重评估及多语言语义词典。现有作者分区适配与自由类型不能当作上述能力已完成。社区托管和远端搜索/发布按用户要求后置。

这些能力需分别收敛数据契约和交互后实施；本次优先补齐已存在本地资产模型的实际入口与正确性。真实游戏内文件选择、服务器往返、UI 裁剪及删除后预览清理仍需手工验收。

游戏内验收应覆盖：普通玩家不能删除共享库但能删除私人库；玩家成为 OP 后仍删除其当前可见的私人记录；多人连接下库卡片可见、缩略图逐步生成且主动加载优先；600 方块以上资产保存后能加载、导出并重新导入复用；同一内容不同许可的来源分别导出；取消保存文件选择、选择已有文件及下载断线均不会覆盖本地文件。切换服务器后不保留前一服务器的构件预览。
