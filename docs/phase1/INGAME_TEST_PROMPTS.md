# Phase 1 · 游戏内测试提示词

配合 [INGAME_ACCEPTANCE_MATRIX.md](INGAME_ACCEPTANCE_MATRIX.md) 使用。  
每条提示词原样粘贴到 FormaCraft Chat；测完再 Confirm → Undo → Redo（除非场景另有说明）。

## 测试前准备

1. 平坦草地或平整测试平台；记下脚下坐标。  
2. Python 后端已启动；Chat 能发请求。  
3. 每次新场景换一块空地（间隔 ≥40 格），避免 Undo 栈交叉干扰判断。  
4. 预览出现后先走动确认世界未变，再点确认。

## A. 主干路径（优先）

### A1 · 小型住宅（必测）

```
盖一个 9x7 的单层小木屋，橡木墙，深色橡木屋顶，南侧正门，两侧各两扇窗，屋内有地板。不要地标，不要城堡。
```

备选（若上条风格漂移）：

```
盖一个紧凑的现代小平房，约 11x9，白墙深灰坡屋顶，南向入口一门两窗，单层，普通住宅，不要地标模块。
```

**核对**：预览线框 → Confirm → 门窗屋顶在 → Undo 清空 → Redo 恢复。

---

### A2 · 增量修改（先完成 A1 并 Confirm 留下建筑）

站在 A1 建筑**地面旁**（不要站屋顶上）：

```
只改局部：把这栋小木屋朝南外墙最中间那一段改成玻璃窗带，不要重建整栋，不要移动建筑。
```

备选（更明确 patch 意图）：

```
对当前建筑做增量修改：南立面中部开三格宽的玻璃窗，其余结构不动。
```

**核对**：Chat 应推断为 `PATCH`；应走 Patch 预览（Ticket /「应用补丁」）；若后端仍返回整栋 `mode=build`，服务端会**拒绝落地**并提示，不得在屋顶重建。

若仍整栋重建：记为 **失败**，附截图与提示词。详情见 [INGAME_FINDINGS_2026_10_25.md](INGAME_FINDINGS_2026_10_25.md)。

---

### A3 · FBD 重复亭廊（须明确要求 FBD）

```
请使用 FBD 程序生成：沿东西向一排 3 座小亭子，间距约 8 格，每座 5x5 带坡屋顶和四角柱，材质用墙/屋顶角色，不要普通住宅语义构件，不要地标。
```

备选（更贴近示例）：

```
用 FBD（fbd_program）做重复亭廊：repeat 生成 4 座相同亭子排成一行，柱廊+坡顶，可控过程几何，不要四合院也不要城堡。
```

**核对**：若返回能力缺口且未伪装成普通房 → 按文档可接受；若生成了普通房冒充 FBD → **失败**。成功则 Confirm → Undo。

---

### A4 · 地标 / 精品模块

```
在锚点位置生成大雁塔。
```

备选：

```
在锚点位置生成天坛。
```

```
建造一座明清官式院落（四合院）。
```

**核对**：预览 → Confirm → Undo。地标体积大，Undo 可能较慢，等完成再判断。

## B. 门禁与异常（用 A1 同类提示）

先发 A1 提示词进入预览，再按行操作（不必换提示词）：

| ID | 操作 |
|----|------|
| B1 | Confirm 成功后立刻再 Confirm / 再点确认 |
| B2 | 预览后点取消，再执行 `/forma_confirm` |
| B5 | Patch 预览后（A2）传送到距原点 >100 格再确认 |
| B4 | A2 预览出现后，手动挖掉预览目标格再确认 |

过期 B3：发 A2 出 Patch 预览后等待 >5 分钟再确认（或看服务端 Ticket TTL）。

## C. 玻璃板 Undo（专用提示）

平坦空地：

```
生成一排东西向的玻璃板走廊：长 12 格、宽 1 格、高 3 格，两侧玻璃板墙，顶部玻璃板，南端开口，只要玻璃结构，不要整栋房子。
```

备选（染色 / 铁栏）：

```
生成一圈白色染色玻璃板围栏，边长 8 格，高 2 格，四角闭合，只要玻璃板，不要屋顶。
```

```
生成一条长 10 格的铁栏杆矮墙，高 2 格，直线排列。
```

**C1/C2 步骤**：Confirm → Undo → Redo → 再 Undo → 再 Redo；连接方向变化不应误报「玩家已修改」。

**C5**：Confirm 后手动把一块玻璃换成石头或桶装水弄成含水，再 Undo → 应冲突/拒绝覆盖，不能静默成功。

**C3/C4（栅栏/石墙，验证未错误放宽）**：

```
生成一条长 10 格的橡木栅栏，直线，高 1 格。
```

```
生成一条长 10 格的石砖墙，直线，高 2 格。
```

Confirm 后在旁再放方块改变连接，再 Undo：若因连接变化被当成「已正确」而跳过真实冲突，记问题；期望是严格冲突或仍可完整撤回到空气（视快照），**不能**用玻璃板那套软匹配吞掉材质级错误。
