# 2026-10-27 游戏反馈回放

## 日志范围

本轮日志跨越零点：`run/logs/2026-10-26-4.log.gz` 与 `run/logs/latest.log`。
八份实际模型响应保存在 `src/test/resources/regressions/ingame_20261027/`。

## 根因与修复

1. 增量预览：文字颜色缺少 ARGB alpha，Patch 使用了大面积确认面板。已补全不透明文字颜色，并将 Patch 确认区缩小到底部。新增窗户不再采用模型给出的槽位偏移；依据建筑记忆的实际落地原点和现场入口定位原墙。入口可以是门方块，也可以是带楼板、门楣和两侧门框的空门洞。不能唯一确认时拒绝落地；屋顶、柱子、楼梯和半砖不作为开窗墙体。
2. 水岸木屋：FOUNDATION 的 `foundation_type=stilts` 原先仍生成实心石基。现在生成贯穿声明高度的九根木桩，桩间不填充，并作为已设计支撑阻止地形层附加石柱。室外直梯关闭默认底部支撑。
3. 木亭：开敞识别漏掉 `wall_type=none` 加 `open_sides` 的表达。统一进入柱梁开敞路径。
4. 徽派：无显式锚点的中央天井按左下角展开，与南厢房相交。仅在居中后不碰墙且被至少三面围合时采用中心锚点；不放宽覆盖授权。
5. 土坯楼梯：模型以楼板上方的站立空间而非楼板方块作为两端 Y。对同时满足上下层这一偏移关系的室内梯统一下移一格。
6. 双塔：通道只切开一层墙；旧立面方向还与世界外法线相反。为相邻主体补齐绑定到目标主体的另一侧门洞，显式转换朝向，并保留门洞脚下的楼板，避免打通后仍无法行走。目标塔具有内部入口，不再需要自动补外门。

## 验证
