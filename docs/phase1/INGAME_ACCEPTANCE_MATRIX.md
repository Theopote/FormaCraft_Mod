# Phase 1 · 游戏内验收矩阵

状态：待执行 · 基线 `ff7039cd` · 2026-10-25  
用途：标准化 Preview / Confirm / Apply / Undo / Redo；**不得**用离线 CI 结果填写「通过」。

硬门槛（任一失败即整案失败，不可被观感分抵消）：

1. 世界写入仅发生在 Confirm/Apply 之后（预览不改世界）。  
2. Confirm 后体素与冻结预览一致（允许邻居自动连接类状态按合同容错）。  
3. Undo 后目标格恢复到建造前；Redo 可恢复建造结果。  
4. 无不可撤销的错误写入被记为成功。  
5. 失败/取消/过期不会留下「半确认」可重放状态。

## 填写约定

- 结果只允许：`通过` / `失败` / `受阻` / `待测`。  
- `受阻` 必须写清环境原因（无服、无后端、模组未加载等）。  
- 失败必须附最小复现（提示词或 fixture 路径 + 维度坐标）。  
- 未实际进游戏的项保持 `待测`，禁止改写为通过。
