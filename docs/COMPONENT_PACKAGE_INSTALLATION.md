# 离线包安装 v1

ComponentPackageInstallations.install 接收包路径、环境、可信服务器 SaveContext 和显式本地别名。读包、兼容性与变化规则检查先于写盘。未知来源且没有显式规则的旧程序化构件暂不安装，避免依赖未打包的外部原型；CAPTURED 原件和有作者规则的资产可安装。

目标为全局库或当前玩家库下 packages/localId/，目录内仅有 source.fccomponent.json 与 receipt.json。先写同目录临时区，再以原子目录移动发布；不支持原子移动的文件系统返回错误。失败临时区不参与目录读取；安装不执行旧保存函数的自动修复、侧车生成或世界写入。

回执绑定本地别名与原始 contentRef。原包载荷、作者、许可、独立训练授权和依赖声明完整保留。运行时副本只替换本地 id 与安全的、内容哈希派生的 archetypeRef；不改原包或作者的变化权限。

默认拒绝可见库同名资产及目标中的孤立文件/目录，即使 SaveContext 允许普通覆盖也不覆盖包。私人安装不得遮蔽全局资产。安装与普通保存共享进程内互斥，包安装另有文件锁协调进程。发布目录预检查在锁内进行，不保护外部程序直接篡改磁盘的行为。

ComponentStorage 合并导入目录，旧平面 catalog 不持久化这些派生条目。普通保存拒绝覆盖已安装 ID；删除先退役安装目录，再清理已知文件。目录读取会重验回执、包内容和当前环境，损坏资产不会作为有效构件返回。

首版不生成缩略图，不提供升级/替换或批量事务；尚未接入游戏导入界面和网络接口。调用者必须从现有服务端权限判断产生 SaveContext，不能信任客户端传入的写库标记。
回执额外记录稳定的 manifest 指纹，防止只保留载荷哈希时忽略许可或训练授权篡改。安装复制已校验的内存快照，源文件后续改变不影响安装内容。当前目录合并会重验已安装包，尚未提供大型库的元数据缓存优化。
