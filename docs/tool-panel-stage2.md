# 工具面板第二阶段：笔刷历史与路径参数

## 笔刷

- 左键按住涂抹、右键按住擦除，每次完整笔画记录为一步；清空也能撤销。
- 工具面板提供撤销／重做按钮，快捷键为 Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z。
- 笔刷工具激活时，这些快捷键只操作笔刷历史，历史为空也不会落到建筑撤销。
- 输入框获得焦点时，撤销键优先交给输入框；生成确认预览保持原来的建筑历史语义。
- Esc 取消当前尚未结束的笔画，恢复笔画前的选择；切换工具保留已经涂抹的结果。
- 采用增删集合记录差异，最多保留 32 步，不会每个 tick 复制整个区域。

## 路径

- 新路径默认折线，可切换为平滑曲线；切换绘制模式不会改变已有路径。
- 提供生成路径切换与逐条删除，新增完成路径自动成为当前生成路径。
- 其他路径仍显示为参考，选中的生成路径更亮。
- 单路径生成请求、提示词骨架及工具约束快照都只使用当前选择，避免将独立路径首尾相连。
- 走廊半径可设为 1～32 格，并沿原有请求字段传递；这是走廊影响范围，不代表所有生成器最终道路宽度都等于其直径。
- 用途可选择自动、道路、城墙、桥梁、沿线建筑。显式用途优先，自动模式继续从文本推断。
- 导出曲线节点时移除相邻重复方块坐标，避免重复采样膨胀请求。

## 自动与手动验收

新增回归覆盖：多 tick 笔画合并、擦除与清空恢复、取消笔画、重画后重做失效、空操作保留重做、历史上限、独立路径切换、绘制模式、半径与用途导出、删除清空、重复点击、请求与快照选择一致。

本轮连同第一阶段及提示词回归共 30 项测试通过，0 失败、0 错误、0 跳过；最终编译与 remapJar 打包成功。

游戏内需要检查：

1. 画两笔后连续撤销／重做；局部擦除和清空后也应恢复原范围。
2. 历史为空时按 Ctrl+Z，世界中的建筑不得被撤销。
3. 笔画中按 Esc、切换工具，分别验证回退与保留；确认预览内测试原来的建筑撤销。
4. 画两条相距较远的路径，切换当前生成路径，检查预览不会出现两条路径之间的连接线。
5. 分别画折线和曲线，调整半径与用途，再核对请求和生成预览。
6. 在较小窗口、不同 GUI 缩放下滚动路径选项，检查按钮显示和点击范围。

本阶段未修改网络协议，仍然是每次选择一条路径生成。多路径同时生成、路径节点拖拽、约束独立启停以及基准平面／吸附继续列入后续阶段。尚未进行游戏内实测。
