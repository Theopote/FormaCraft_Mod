# 工具面板第一阶段修复

本阶段聚焦已有工具的正确性和基础交互，不改变生成器及网络协议。

## 已实现

- 选区六面拖拽统一使用包含末端方块的坐标，只改变目标轴，最小尺寸为一格。
- 拖拽通过鼠标射线与固定操纵轴计算，避免命中地形变化导致跳动；取消拖拽恢复开始前范围。
- 轮廓默认上限从额外 20 格改为世界顶端；存在选区时仍继承其高度，并在面板显示实际 Y 范围。
- 轮廓和语义区域校验重复点、零面积与自交；允许点击首点闭合。无效多边形保留草稿供退点修改。
- Esc 取消未完成操作；路径、多边形和标签支持 Enter 完成、Backspace 退点。文本编辑和生成预览保持自己的输入优先级。
- 标签完成不再要求鼠标命中方块，高度以首个绘制点为准。
- 笔刷右键改为局部擦除，清空仍使用面板按钮；UI 点击不能发起笔画。
- 笔刷过滤预先建立 XZ 哈希集合，查询保留孔洞并允许沿 Y 扩展。
- 选区、轮廓、保护区、语义标签和对称标记支持切换工具后持续显示。
- “无”改名为“锚点”；面板显示默认定位依据与保留范围，说明修改区域模式优先选区。
- 自定义对称轴拒绝两个相同的 XZ 位置；切换工具、关闭 HUD 或进入锁定预览会取消未完成手势。

## 游戏内验收

1. 创建 10×10×10 选区，依次拖动六个面；未操作的方向尺寸必须不变。拖拽中按 Esc 应恢复原范围。
2. 地面绘制轮廓，检查高度说明；生成超过 20 格的建筑，确认不再受旧的默认上限影响。已有选区时核对继承高度。
3. 多边形点击首点后完成；再尝试共线点及交叉轮廓，应提示无效，退点后可修正。
4. 标签绘制三点后看向天空，右键或 Enter 应能完成。
5. 刷出一片区域，右键擦除局部；移动到面板点击半径按钮，不能新增笔画。切换工具后保留范围仍应可见。
6. 路径绘制时测试退点、完成和取消；标签输入框获得焦点时，Backspace 必须继续编辑文字。
7. 打开生成确认预览，验证 Enter 确认、Esc 取消，不触发工具绘制。

尚未执行游戏内验收。天空视角下的叠加层渲染、缩放和不同分辨率需要实际客户端确认。
