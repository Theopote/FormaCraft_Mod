# 矩形坡顶几何

双坡屋顶的屋脊沿长轴延伸，坡度沿短轴计算。高度使用到最近两侧边缘的整数距离，奇数跨度单脊、偶数跨度双格屋脊，避免两侧坡面不对称。

四坡屋顶使用到四边的最小距离计算高度，长方形沿长轴形成屋脊，四边檐口都落在屋顶构件的接合高度。旧算法使用到中心的最大距离，在长方形两端产生负高度并跳过输出，导致漏顶；现已移除此缺失原因。现有 pyramid 类型复用四坡生成器，同样受此修复影响；尚未提供独立的长方形金字塔比例规则。

高度仍遵守 `roof_height` 或 dimensions.height，屋檐扩展后再计算坡面，保留平面形状过滤。测试检查实际方块输出的矩形投影覆盖、长轴方向、奇偶跨度对称和檐口高度。

补齐屋面后，完整编译回归暴露楼板体块被错误推断为建筑的旧问题。`extrude_mode=plate` 现在跳过自动立面、入口和屋顶推断，保留楼板本身及显式构件，避免虚构的屋顶阻止正常门洞和楼梯。

本批不构成独立的最终坡顶验收：异形裁剪、山墙填充、超陡坡面连续性、歇山及重檐接缝仍待完善。没有将整个屋顶包围盒填成实体。
