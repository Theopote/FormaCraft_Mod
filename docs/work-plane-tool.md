# 基准平面工具

## 使用

1. 打开工具面板，选择“基准平面”。
2. 左键点击方块，取其顶面上方的整数 Y 作为建筑起始高度；世界中显示青色参考网格。
3. 拖动黄色竖直箭头调整高度，或输入 Y 后按 Enter／“应用 Y 坐标”。也可使用高度 ±1 按钮。
4. 选择“固定高度”，右键或点击“锁定平面”。
5. 切换到轮廓、路径或笔刷绘制。它们使用鼠标射线与平面的交点，前方无方块也能操作；平行、背向或超出交互距离的射线不会意外取点。
6. 发送新建请求。面板会显示固定基准高度，已有锚点／轮廓／选区仍决定水平位置和边界；没有这些数据时使用平面中心定位。

“跟随地形”恢复原有地形取点与生成策略，参考平面不会限制绘制高度。右键锁定仅在基准平面工具激活时操作，不改变路径等工具原有的右键行为。

拖动中按 Esc 恢复拖动前高度。切换工具保留当前高度；“清除基准平面”取消平面和锁定。切换世界或维度时自动清除平面。

## 与现有范围的关系

- 轮廓、路径和笔刷的已有数据不会随平面整体移动；应先定平面，再绘制新范围。
- 选区和禁区仍拾取真实方块，不被平面替代。
- 选区的三维边界仍然有效。若基准高度超出选区，面板会提示调整选区，避免生成被裁剪。
- PATCH／MODIFY_REGION 继续使用原有编辑坐标，固定平面不平移已有建筑的编辑操作。
- 新建请求携带 `fixedBaseY`，经请求压缩和 C2S 编解码保留。主要 LlmPlan 预览流程以该高度覆盖模型的锚点高度，并跳过自动落地和自动地坪准备；建筑自身的构造和质量检查继续有效。
- 绘制路径导出骨架时关闭自动贴地，保留绘制标高；用途和走廊参数继续使用原有路径设置。

## 验证

自动回归覆盖：空中求交、向上求交、负坐标、平行／背向／超距射线、锁定与跟随地形、世界高度钳制、锚点与约束保留、编辑模式不平移，以及固定高度请求的压缩和真实网络编解码往返。

需在游戏内验收：黄色箭头拖动手感、无方块时网格持续显示、GUI 缩放后的输入点击、悬空路径／轮廓／笔刷、固定标高的新建预览及跨维度清理。尚未执行游戏内实测。
