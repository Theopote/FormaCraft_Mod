# 构件缩略图与捕获预览

缩略图使用客户端当前资源包的烘焙方块模型、UV 和原始材质像素。完整方块状态参与模型选择，所以楼梯朝向、台阶上下半部、门的开合、窗格连接形状会保留。

参考 `treefactory-light` 的模型预览思路。本项目将模型和材质在客户端线程复制为独立数组，在后台做正交投影、纹理采样和深度测试，输出透明背景 PNG。使用两倍分辨率绘制后缩小；投影后的实际几何边界决定居中和缩放。玻璃透明像素按深度混合，材质镂空区域保留，内部被完整不透明方块覆盖的可裁剪面不参与绘制。

构件库首次展示时根据 JSON 定义自动生成新版缩略图，因此已有构件无需重新捕获。此更新保存在客户端内存缓存中，不改写已有 PNG。重新保存构件时会存入新版 PNG。目录更新时间用于刷新缓存；资源包重载会清除库缓存和 GPU 图像纹理。磁盘读取和栅格化在后台执行，同时最多准备两个构件，图像缓存最多保留 96 项。界面以单个纹理矩形绘制一张图片。

捕获预览独立于锚点确认，支持方框与不规则选区。每 750 ms 检查选区方块内容，世界内替换方块后也会刷新。适配后的预览使用同一渲染器。构件库按可用宽度调整网格列数，选中后显示大图和尺寸。面板保持原有透明背景。

## 范围与验证

当前呈现的是静态方块模型，动画材质采用首个有效帧，草叶等使用默认色调。箱子、旗帜等依赖方块实体专用渲染的内容、液体和实体不包含完整动态效果；自定义依赖世界上下文的模组模型也需要另行接入。阴影为模型面方向的固定光照，不包含游戏世界的实时光照或阴影。

`ThumbnailRasterizerTest` 验证长高构件居中和边距、遮挡与输入顺序无关、透明度、共享三角形边、玻璃混合、镂空和 UV 材质细节。`build/thumbnail-review-window.png` 和 `build/thumbnail-review-tall.png` 是人工组合几何配合原版材质的离线检查图，用于检查栅格化效果，不是游戏内截屏。原生模型读取、资源包重载和界面操作仍需游戏内最终验收。
