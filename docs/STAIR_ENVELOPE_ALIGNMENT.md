# 楼梯与外墙边界（2026-10-04）

## 游戏复测定位

13:59、14:03 的直梯端点是中心线坐标，但靠墙位置只给了一格偏移。三格宽踏步需要向两侧各占一格，净空清除因此碰到外墙。双栋样例顶部平台还超出主体深度。旧执行器正确执行了传入几何，但没有检查它是否在建筑内部。

14:01 的塔楼主体 slot_id=tower_shell，环梯 slot_id=ring_staircase；layout.slots 为空。旧规范化按相同 slot_id 查主体，查找失败后把环梯相对位置 (-6,0,-6) 当作中心，而主体把它当墙角。导致楼板和楼梯向外偏移六格。主体 shape=cylinder 在 MASS_MAIN 中也未被识别，回退成矩形；目前作为 circle 别名处理。

真实脱敏响应保存在 `src/test/resources/regressions/stair-envelope/1.json` 至 `6.json`。

## 修复约定

- 无实际 layout slots 时，优先同 slot 主体，否则按平面距离匹配 MASS_MAIN；有真实不同 slot 坐标系时不猜测跨 slot 关系。
- 直梯使用踏步中心线及准确横向宽度，连同顶部平台整体限制在主体墙厚内侧。优先平移；不足时缩短平台，再尝试旋转平面方向。圆形主体还检查包络四角。完全放不下则返回 E_STAIR_ENVELOPE_FIT，不通过切外墙放行。
- `params.exterior=true` 的显式外梯保留原位置。没有主体的独立楼梯不做主体对齐。
- 环梯核心贴回主体中心，半径 6 的离散主体采用 13×13 尺寸。圆形楼板半径避开墙厚，仍保留净空和楼板洞口。
- 只调整平面位置与平台长度，本批不重新设计楼梯层高、入口至楼梯路线或任意异形体量。

回归检查覆盖真实直梯的宽度、两端和平台包络，环梯中心及楼板半径，并检查规范化重复执行结果一致。游戏最终外观仍需重新生成验收。
