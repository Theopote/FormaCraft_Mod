# 固定风格样例验收

四份输入随 mod 打包，种子均为 `20261004`。`/forma_style_case` 列出样例，参数支持补全。
命令走生产 LlmPlan 预览、地形适应和质量检查；不会直接放置方块。使用 `/forma_confirm`
确认建造，`/forma_cancel` 取消，`/formacraft_undo` 撤销已确认的建造。

| ID | 输入目标 | 重点检查 |
|---|---|---|
| wood_stone | 石砖墙、云杉木山墙屋顶 | 木石层次、屋檐材料族、窗墙比例、入口尺度 |
| modern_flat | 白混凝土、平顶、禁止复杂装饰 | 平顶收边、窗带连续性、不附加古典装饰 |
| hui_white_black | 白墙、深板岩瓦山墙屋顶 | 白黑对比、屋面与檐部接缝；仅徽派材料基线，不表示实现马头墙 |
| two_materials | 同 slot 两栋，石砖/橡木墙、瓦/云杉屋顶 | 每栋独立门窗与屋顶，材料不串栋 |

## 固定场景和视角

新建专用创造模式超平坦测试世界（开启命令），不要在已有作品上放置样例。
默认超平坦地面顶面为 Y=-60；自定义世界需相应调整高度。四例依次在 X=0、100、200、300。
每次 `/tp @s X -60 0` 后运行 `/forma_style_case ID`，检查预览再 `/forma_confirm`。
固定晴天正午：`/weather clear`、`/time set noon`、`/gamerule doDaylightCycle false`。

单栋正面斜视：`/tp @s X-16 -43 -23 -38 20`（将 X-16 替换为计算后的数字）。
双栋全景：`/tp @s 322 -36 -38 0 24`。统一 FOV、窗口尺寸和资源包，F1 隐藏界面后 F2 截图。
额外检查背面屋檐接缝、入口通行、两层窗口及室内楼板，再恢复正面视角截图。
记录 mod 版本、世界类型、FOV、资源包、输入 ID、实际 origin 和截图文件名。

## 验收边界

自动回归确认样例非空、固定输入完整后处理重放一致，以及逐栋墙材、屋面材料、玻璃和入口存在。
它不模拟真实世界、地形适应、质量修复或执行器；也不评价建筑美观。
游戏截图与人工检查完成前，四例的视觉验收状态均为 **待验收**。
