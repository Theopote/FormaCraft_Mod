# FormaCraft 屋顶图册吸纳记录

研究材料为《屋顶生成图册》及八张配图，以及《建筑立面划分：设计原理与程序化编码》和它的粘贴版。下表按生成模型整理，建筑术语和尺寸范围用于选择样式，实际尺寸以计划及方块约束为准。

| 体系 | 可复用的生成规则 | 接入位置 |
| --- | --- | --- |
| 中式与日式 | 将足迹、山面收进、出檐与举架剖面分别建模。硬山与悬山主要靠山面是否出檐区分，歇山与入母屋复用上部山面、下部四坡的几何。 | 沿用现有歇山、庑殿和入母屋路径。首批用正弦剖面生成双坡卷棚。 |
| 欧洲折坡与民居 | 同一折线剖面沿一个轴展开是复折双坡，按四边距离采样可做孟莎。盐盒顶用偏心脊线分出长短坡。 | 复折和孟莎已有实现。首批新增盐盒顶，短坡在跨向坐标较小的一侧。 |
| 现代与工业 | 蝶形顶的中线是谷线，锯齿顶每次周期重置形成高侧窗面。 | 现有锯齿生成器可承接采光带。蝶形顶需同时定义谷线、屋面与墙体的收口。 |
| 穹顶与南亚、东南亚塔顶 | 穹顶、洋葱顶与塔顶按标高取半径或平面轮廓。外鼓轮廓允许同一平面位置出现多个高度，层塔还需要层间壁体。 | 复用现有穹顶和塔体体系。洋葱顶已有逐层半径采样；叠檐与层塔保留独立的层间结构。 |
| 哥特 | 按开间划分拱面，再布置对角肋、横肋和装饰肋。 | 肋网应对齐体量的开间轴和柱头，与外部坡顶分开生成。 |

通过 LlmPlan 构件的 `params.roof_type` 选用 `juanpeng` 或 `saltbox`，也识别“卷棚顶”和“盐盒顶”。两者复用现有屋高、脊向、出檐、足迹掩码和材质规则。缓坡使用同材质下半砖，接近一格一升的坡段使用朝向屋脊的楼梯，陡坡和最高处使用整块。材质缺少对应变体时使用原方块。相邻坡面列之间补齐竖向接缝，阁楼空间保留。双坡卷棚的圆弧是体素近似。盐盒顶的脊线默认落在跨向约三分之一处，小跨度会压缩长短坡差异。

## 落地时的取舍

钟形顶的双坡形式为折线顶（`bellcast`、`钟形顶`、`钟形双坡顶`），檐口段缓、上部段陡。`bellcast_break_run_fraction` 控制檐口到屋脊水平距离的折点比例，默认 0.25；`bellcast_break_rise_fraction` 控制折点高度比例，默认 0.1。两者均须在 (0,1)，高度比例须小于水平比例。支持 `ridge_axis`、山墙封闭、楼梯/半砖铺瓦及陡坡接缝填充；四坡形式使用 `bellcast_hip`／`钟形四坡顶`／`四坡钟形顶`，共用上述折点参数。四坡从矩形四边等距向内起坡，短边决定起坡距离，长矩形保留中央脊线；正方形收为中心顶点。交角和脊线用整块，单向坡面按坡度铺瓦。支持出檐和竖缝填充，内部留空；支持矩形和正交 L 形足迹。L 形使用 `plan_type=l_shape`、`l_cut` 和 `l_corner`（NW／NE／SW／SE），内外檐同步起坡，内檐等距线相交形成谷线；谷线用整块收口，单向坡面复用铺瓦规则。折点比例按 L 形两翼中的最大起坡距离计算，出檐同时移动内外檐。


穹顶可用 `dome_profile` 选择剖面。`hemisphere` 使用半圆截面，`pointed` 使用两段圆弧在顶点相交的尖拱截面，省略时沿用 `legacy`。也可直接请求“半球穹顶”（`hemispherical_dome`）或“尖拱穹顶”（`pointed_dome`）。命名形式与剖面冲突时报告几何错误。剖面高度按屋高预算缩放，可与鼓座、肋纹及中央天窗组合；多面足迹用多面穹顶类型配合 `dome_profile` 指定。

圆穹顶和多面穹顶可设置 `dome_oculus_radius`，以方块为单位在穹壳中心留出圆形天窗。默认 0；非零半径必须让洞口周围保留至少一格连续穹壳。开孔可与鼓座和肋纹组合，鼓座仍沿外轮廓生成。指定 `dome_oculus_glass_block` 可沿原穹壳高度铺设玻璃覆盖，支持已注册的普通玻璃、染色玻璃和遮光玻璃方块。

圆穹顶和多面穹顶可用 `dome_drum_height` 加入空心鼓座。鼓座占用总屋高预算，穹壳至少保留两层。鼓座沿穹壳实际足迹的边界生成，并补齐量化边缘的接缝；可用 `dome_drum_block` 指定材质，省略时使用墙体材质。设置 `dome_rib_count` 可在穹壳上布置 1–32 条等角径向肋纹，默认 0。用 `dome_rib_block` 指定肋纹材质，省略时取墙面装饰材质。肋纹沿现有穹壳铺设，保留穹顶高度和鼓座材质。

L 形孟莎顶可组合 `roof_type=mansard` 与 `plan_type=l_shape`，并用 `l_cut`、`l_corner` 和 `overhang` 定义缺角及出檐。内外檐同步起坡，谷线整块收口；折点有效范围按两翼实际最大起坡距离校验，过窄且无法容纳两段坡面的足迹会报告几何错误。开启老虎窗而未指定窗数时，在选定正面最长的连续等高折线带上自动安排至多三扇；显式窗数超出容量时仍报告错误。

四坡孟莎顶（`mansard`）可用 `mansard_break_run` 指定从檐口到折点的水平格数，并用 `mansard_break_rise` 指定折点相对檐口的抬高格数。折点须位于屋面中部之前，并保持下陡上缓。开启 `roof_dormers` 时，老虎窗随折点移动，按实际屋面定高。指定正整数 `mansard_dormer_count` 可启用并指定窗数，生成器会在最长的连续前坡折线带上排布，每扇窗占三格，窗间至少留一格。数量超出容量时报告几何错误；显式关闭 `roof_dormers` 优先。

复折双坡顶（`gambrel`）可用 `gambrel_break_run_fraction` 和 `gambrel_break_rise_fraction` 调整折点。前者从檐口量取半跨中的水平比例，后者是折点占总起坡高度的比例。默认值分别为 0.35 和 0.65。两者都必须大于 0 且小于 1，且高度比例必须大于水平比例，以保持下陡上缓。坡面高度跳变处补齐竖缝。

十字双坡顶（`cross_gable`）合并互相垂直的两个双坡剖面，默认等高。可用 `ridge_axis` 指定主脊轴，再用 `cross_gable_secondary_height` 指定侧翼屋高，取值为 2 到主屋屋高之间的整数。降低侧翼后，侧脊在主屋坡面终止，谷线随两组坡面的交线移动。坡面按取整前的坡度使用楼梯或下半砖，屋脊和谷线交接带用整块收口，四个山墙沿足迹边界封闭。

工业锯齿顶（`sawtooth`）可用 `sawtooth_glazing_facing` 指定高侧窗朝向（`north`、`south`、`east`、`west`），朝向同时决定重复轴。用 `sawtooth_count` 指定齿数，跨度均匀分配给各齿，每齿至少占两格。省略朝向时沿用 `sawtooth_axis`。

蝶形顶（`butterfly`）沿 `ridge_axis` 布置低谷。两侧屋面向中央下降，谷底用整块连续铺设。高檐与端墙沿宿主足迹边界收口，内部保留净空。首版表达天沟几何。

盐盒顶可用 `saltbox_long_slope` 指定长坡面向 `north`、`south`、`east` 或 `west`，屋脊取垂直于该方向的轴线。用 `saltbox_ridge_fraction` 从短坡檐口量取脊线位置，取值大于 0 且小于 0.5，默认 1/3。按格取整时只要跨度允许就保留长短坡差异。

硬山卷棚（`juanpeng_yingshan`）与悬山卷棚（`juanpeng_xuanshan`）共用卷棚剖面。硬山在两端山墙平面收口，侧檐仍按出檐值生成。悬山沿屋脊方向挑出山墙，未指定正出檐时默认挑出两格。

正交 L 形单檐四坡顶已接入 `roof_type=hip` 与 `plan_type=l_shape` 的组合。屋面同时从外檐与缺角两侧起坡，内檐等距线形成谷线。上坡方向明确的坡面复用楼梯和下半砖选材，谷线、脊线与陡坡使用整块，并用现有规则填充竖缝。测试覆盖四种缺角方向和出檐。

- 立面报告里可直接转化为产品约束的是跨层共享开间网格、基座／墙身／檐部各自的洞口规则，以及门窗与墙垛共同求解。已有 `BayGridResolver` 和 `FacadeLayoutPlan` 可作为接入点。整数分配应先预留墙垛最小尺寸，再分摊余量并保持镜像关系。报告示例的减格分支可能破坏最小宽度。
