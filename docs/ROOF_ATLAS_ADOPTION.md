# FormaCraft 屋顶图册吸纳记录

研究材料为《屋顶生成图册》及八张配图，以及《建筑立面划分：设计原理与程序化编码》和它的粘贴版。下表按生成模型整理，建筑术语和尺寸范围用于选择样式，实际尺寸以计划及方块约束为准。

| 体系 | 可复用的生成规则 | 接入位置 |
| --- | --- | --- |
| 中式与日式 | 将足迹、山面收进、出檐与举架剖面分别建模。硬山与悬山主要靠山面是否出檐区分，歇山与入母屋复用上部山面、下部四坡的几何。 | 沿用现有歇山、庑殿和入母屋路径。首批用正弦剖面生成双坡卷棚。 |
| 欧洲折坡与民居 | 同一折线剖面沿一个轴展开是复折双坡，按四边距离采样可做孟莎。盐盒顶用偏心脊线分出长短坡。 | 复折和孟莎已有实现。首批新增盐盒顶，短坡在跨向坐标较小的一侧。 |
| 现代与工业 | 蝶形顶的中线是谷线，锯齿顶每次周期重置形成高侧窗面。 | 现有锯齿生成器可承接采光带。蝶形顶需同时定义谷线、屋面与墙体的收口。 |
| 穹顶与南亚、东南亚塔顶 | 穹顶、洋葱顶与塔顶按标高取半径或平面轮廓。外鼓轮廓允许同一平面位置出现多个高度，层塔还需要层间壁体。 | 复用现有穹顶和塔体体系。洋葱顶已有逐层半径采样；叠檐与层塔保留独立的层间结构。 |
| 哥特 | 按开间划分拱面，再布置对角肋、横肋和装饰肋。 | 肋网应对齐体量的开间轴和柱头，与外部坡顶分开生成。 |

通过 LlmPlan 构件的 `params.roof_type` 选用 `juanpeng` 或 `saltbox`，也识别“卷棚顶”和“盐盒顶”。两者复用现有屋高、脊向、出檐、足迹掩码和材质规则。缓坡使用同材质下半砖，接近一格一升的坡段使用朝向屋脊的楼梯，陡坡和最高处使用整块。材质缺少对应变体时使用原方块。相邻坡面列之间补齐竖向接缝，阁楼空间保留。双坡卷棚的圆弧是体素近似。盐盒顶的脊线默认落在跨向约三分之一处，小跨度会压缩长短坡差异。

## 落地时的取舍

工业锯齿顶（`sawtooth`）可用 `sawtooth_glazing_facing` 指定高侧窗朝向（`north`、`south`、`east`、`west`），朝向同时决定重复轴。用 `sawtooth_count` 指定齿数，跨度均匀分配给各齿，每齿至少占两格。省略朝向时沿用 `sawtooth_axis`。

蝶形顶（`butterfly`）沿 `ridge_axis` 布置低谷。两侧屋面向中央下降，谷底用整块连续铺设。高檐与端墙沿宿主足迹边界收口，内部保留净空。首版表达天沟几何。

盐盒顶可用 `saltbox_long_slope` 指定长坡面向 `north`、`south`、`east` 或 `west`，屋脊取垂直于该方向的轴线。用 `saltbox_ridge_fraction` 从短坡檐口量取脊线位置，取值大于 0 且小于 0.5，默认 1/3。按格取整时只要跨度允许就保留长短坡差异。

硬山卷棚（`juanpeng_yingshan`）与悬山卷棚（`juanpeng_xuanshan`）共用卷棚剖面。硬山在两端山墙平面收口，侧檐仍按出檐值生成。悬山沿屋脊方向挑出山墙，未指定正出檐时默认挑出两格。

正交 L 形单檐四坡顶已接入 `roof_type=hip` 与 `plan_type=l_shape` 的组合。屋面同时从外檐与缺角两侧起坡，内檐等距线形成谷线。上坡方向明确的坡面复用楼梯和下半砖选材，谷线、脊线与陡坡使用整块，并用现有规则填充竖缝。测试覆盖四种缺角方向和出檐。

- 以卷棚公式和图 4 的体素示意为准。图 3 和图 7 的部分二维示意把屋脊和檐口的高低画反，截面测试同时锁定最低檐口和最高屋脊。
- 连续性以相邻列有没有实体接合判断。陡坡可以跨多格高度，只要把中间的竖面封住。
- 楼梯、半砖和整块可按连续坡度选择，之后再做高度量化。现有生成器按楼梯的高半部设置朝向，因此朝向沿上坡。脊线也应从原始剖面的转折或坡面边界推导，避免将取整产生的台阶识别成脊。
- 立面报告里可直接转化为产品约束的是跨层共享开间网格、基座／墙身／檐部各自的洞口规则，以及门窗与墙垛共同求解。已有 `BayGridResolver` 和 `FacadeLayoutPlan` 可作为接入点。整数分配应先预留墙垛最小尺寸，再分摊余量并保持镜像关系。报告示例的减格分支可能破坏最小宽度。
