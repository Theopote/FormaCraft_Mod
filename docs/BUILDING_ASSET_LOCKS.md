# 建筑构件锁与本地复现

状态：已接通编译、整栋预览自动保存及命令入口，最终隔离回归通过；真实游戏内尚未验收。社区托管与远端索引继续后置；不做旧数据迁移。

## 范围与契约

对使用构件库的 components[] 整栋 BUILD 预览，记录实际发出的构件使用，而非把所有检索候选写入依赖。原包按载荷及 manifest 双指纹锁定，保存适配后的定义和每次安装的坐标、朝向、镜像、材质请求及随机种子。最终通过质量检查的结构另存为相对建筑原点的 Patch 快照，保证删除原件后仍可准确预览。

编译结果显式携带依赖数据，不让 ThreadLocal 跨异步任务传递。收集器只在一个编译调用期间生效，退出和异常时恢复原作用域；无构件库使用的生成保持现有行为。没有包身份的内部生成定义不伪装为已锁定社区资产。

锁记录是可复用方案，不宣称建筑已建成。保存发生在正式预览发布前，锁目录原子提交；失败时不发布这个依赖不完整的预览。原包快照归属于当前世界和玩家，删除可见库资产不删除锁快照。生成失败和未被采用的检索候选不产生已发布锁记录。

## 本地文件与完整性

世界目录 formacraft/building_assets/players/<uuid>/ 保存 snapshots/ 原包缓存和 locks/<id>/ 锁记录。锁目录保存 manifest.json、input-plan.json、patches.json.gz；manifest 包含所有者、维度、创建时间、编译版本、原点、种子、方案/最终 Patch 文件指纹，以及依赖、适配定义和使用清单。文件名和目录由服务器计算，不接受路径。

原包缓存复用 ComponentAssetSnapshots；锁记录绑定每份源包的两个指纹与适配定义的内容指纹。数据包保持各自原始许可/训练声明，不把多个来源授权合并。完整性检查不是作者认证。缓存跨方案去重，但不自动清除仍被锁记录使用的快照。

初版限制单个方案 1,000,000 个最终方块，解压 Patch JSON 128 MiB，锁清单 16 MiB，输入方案 2 MiB；超过范围明确失败，不截断。读写均限制大小并校验哈希，严格 UTF-8，拒绝路径重定向和损坏快照。锁 ID 独立于名称，每次成功方案生成不同 ID。

收集阶段原包累计上限 32 MiB、适配定义累计上限 8 MiB；最多 256 份原包、1024 种适配定义和 65536 次安装使用。读取时再次限制原包总量。原始下载对象去重后最多 32 MiB，按每份收据计入的原包总量最多 64 MiB。清单同时记录锁格式版本与生产模组版本；读取锁定最终结果不要求重新运行原编译器。仅原包依赖检查仍须符合当前环境。

## 游戏入口与恢复

命令入口 /forma_assets list、/forma_assets preview <id>、/forma_assets restore <id>：

- list 只列当前玩家、当前世界的记录，支持页码。
- preview 检查维度和依赖后，以玩家当前位置为新原点生成普通 Patch 预览；用户仍须确认，沿用现有保护区、世界冲突和撤销流程，不能直接 setBlock。
- restore 把原件恢复到本人私人库；当前可见且两种指纹相同的资产直接复用，返回旧引用到实际本地 ID 的对应关系。OP 不自动公开私人依赖。恢复库不改变世界。

list/restore 可由玩家执行，preview 与现有建筑预览命令一样要求 OP 等级 2。preview 以玩家脚下方块为新原点，沿用当前保护区与轮廓限制，不替用户自动确认。list 页码从 1 开始，每页 10 项。恢复先完整验证锁与所有依赖，再逐项进行现有安装事务；若某个目标库写入失败，返回成功映射和失败项，不能把这种部分恢复称为跨资产原子事务。成功恢复后同步构件目录。

重放使用锁定的最终 Patch，不重新运行 LLM、重新检索或悄悄改用新构件。输入方案和安装参数用于审计及后续编辑，不把“读取锁定结果”称为已支持跨编译器重新生成。Minecraft/模组依赖仍需满足。[跨世界/跨设备导入导出](COMPONENT_PORTABLE_BACKUP.md)已接入命令。已建成建筑的初始锁已接入 [ProjectMemory 绑定](BUILDING_ASSET_MEMORY.md)，增量编辑锁的链式更新仍待实现。
