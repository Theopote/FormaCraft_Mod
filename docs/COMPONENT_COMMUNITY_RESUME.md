# 有界分块与断点续传

新增显式 downloadResumable API，现有完整下载 API 保持只接受 200。续传没有后台重试、游戏入口或自动安装，不访问未配置 authority。

显式 [玩家任务协调器](COMPONENT_COMMUNITY_TASKS.md) 可在有界工作池调用该 API，并把暂存路径绑定到世界/玩家；当前尚无客户端游戏入口或自动重试。

## 协议

每次调用先重取所选发布详情并完整核对 Descriptor/可交付状态。每块请求固定路径和 releaseId，发送 Range=`bytes=start-end` 与 If-Range=强整包 ETag。单块 256 KiB，最后一块允许较短；成功响应必须 206、JSON、identity 编码、相同强 ETag，以及完全对应 start/end/总长度的唯一 Content-Range。声明长度与实际正文长度都须等于该块长度。

服务每个 Range 请求仍须检查所选 release 当前是否可交付；客户端不能用旧详情绕过撤回。返回 200 视为 range_not_supported，不自动把整包拼到前缀后，也不自动切换完整下载。416/错误范围、弱/变化 ETag、超额正文和不同总长均拒绝。需要完整下载时，由调用者明确重新调用现有完整下载 API。

单次调用至多覆盖现有 16 MiB 包上限，最多 64 块；单个 HTTP 请求最多 30 秒，整次续传共享 120 秒截止时间（包括详情与所有块），超时中止活动网络请求。本地文件读取和验证采用阶段前后检查，不强行中断正在执行的 Java/文件系统操作；验证超过截止时间不能返回成功。无自动重试。取消令牌贯穿所有请求与最终验证，已完整提交的块可供下一次显式调用继续。

## 暂存

暂存根目录由可信调用者指定，独立于 receipts/objects 缓存。每个 resume_<digest> 目录按完整 Descriptor 身份隔离，identity.json 记录契约、固定块大小与完整描述符。不可按名称、包内 namespace 或仅 packageSha256 跨发布复用暂存。

块文件为连续索引加本地 SHA-256 的 .part 文件，只有完整核对响应头、范围与正文后才原子发布。恢复时核对身份、文件名/本地 hash、连续性和长度；这些 hash 只检测本地块变化，不代表其已符合最终整包 hash。最后仍从完整原始字节执行整包/载荷/manifest/配置指纹、目标环境及详情声明校验。成功返回 Fetched 后，调用者才能另行保存正式收据。

瞬时服务错误、限流、超时、取消及目标环境不匹配保留完整块；协议错误、对象变化、撤回或最终完整性失败清除可安全识别的该发布暂存，不能产生正式缓存。崩溃遗留 .pending 文件不参与续传，但占用配额。未知文件、目录重定向或不安全路径明确拒绝，不递归删除未知内容。

上限为 16 个暂存传输、64 MiB 总文件字节，每个目录至多 130 个文件；暂存和正式缓存配额分别计算。当前按单个服务器进程独占暂存根设计，同进程同一传输并发调用明确 download_busy；未提供多个独立进程共享同一暂存根的事务协议。没有自动 GC。inspect 可在传输未运行时读取已提交字节进度，达到 100% 也不代表环境或最终验证通过；discard 可显式清除指定描述符的安全暂存。

## 验证

本机临时服务验证：先完成一块再失败/取消、重建客户端后从确切偏移继续、Range 被忽略、范围/总长/ETag 变化、正文超限、撤回重检、本地块损坏和身份隔离。正式缓存与世界在这些测试中不被自动修改。

2026-11-03 最终隔离完整回归 318 项通过，失败/错误/跳过均为 0，其中 CommunityResumeTest 新增 10 项，包含完整字节仍须通过环境验证、单传输并发拒绝、配额与未知文件保护。文档链接与差异格式检查通过。未进行公网、真实 TLS 服务或游戏 UI 验收。
