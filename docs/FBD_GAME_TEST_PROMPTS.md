# FBD 游戏测试提示词（修订版）

修复 Java 代码后需要重新启动开发客户端；仅重启 Python 后端不会加载 Java 修复。
以下正常用例均满足 SHELL_BOX 的 w/d≥5、h≥6 限制。每次选择空地，检查预览、确认和撤销。
返回计划必须包含 ASSEMBLY.params.fbd_program；出现普通建筑不能算作 FBD 测试通过。

## 1. 单体

请使用实验性 FBD，通过 ASSEMBLY.params.fbd_program 建造一座宽7、深7、墙体高6格的小亭，使用 SHELL_BOX 和 FLAT 屋顶，屋檐外伸1格。材质仅使用 wall、window、floor、roof、slab 等语义角色，不使用方块 ID、预设或世界查询。

## 2. 有界循环

请使用 FBD 的 repeat 和 with_frame 建造三座相同的小亭，每座宽7、深7、墙体高6格，采用平屋顶，沿横向排列，中心间距10格。使用循环表达重复结构，不手动复制三套程序。dimensions 应覆盖所有亭子及屋檐。

## 3. 函数

请使用 FBD 定义接收宽、深、高参数的亭子函数，调用三次，尺寸分别为5×5×6、7×7×8、9×9×10格，沿横向排列，中心间距14格，均采用平屋顶。使用语义材质角色，不使用递归。

## 4. 两种屋顶

请使用 FBD 建造两座独立小屋，每座宽9、深7、墙体高6格，中心间距16格。一座采用 FLAT 屋顶，另一座采用 GABLE 屋顶。墙面和屋顶使用相同的语义材质角色，保持屋顶轮廓便于比较。

## 5. 朝向与局部坐标

请使用 FBD 的 with_frame 建造不对称三亭组合：主亭位于局部原点，尺寸9×7×6格；第二座位于局部右侧14格，尺寸5×5×6格；第三座位于局部前方12格，尺寸7×5×8格。全部采用平屋顶，互不相连。程序继承构件朝向。

分别朝四个方向测试，检查相对位置与整体朝向。

## 6. 确定性随机

请使用 FBD，固定 seed 为42，用 repeat 建造五座小亭，沿横向排列，中心间距12格，每座宽、深均为7格。墙体高度通过带稳定标签的 rand 和 floor 在6到10格之间选择整数，全部采用平屋顶。

确定性比较必须重放同一份程序；重新发送提示词可能产生另一份程序。

## 7. 预算拒绝

请使用 FBD，用两层 repeat 尝试生成100×100座小亭，每座宽9、深9、墙体高8格，间距12格。保留完整数量，不自动缩减。我在测试预算拒绝，不应生成任何部分建筑。

模型可能自行返回能力缺口。那只验证了模型的拒绝行为，不能证明 Java 预算门禁已执行；必须结合返回计划和服务端错误来源判断。
