# 后处理外壳完整性保护（第五批）

日期：2026-10-04。

第七批扩展：接收 [生成器表面来源](GENERATED_SURFACE_PROVENANCE.md)，保护已记录的曲面墙体和体块外屋檐；未接入来源的生成器仍使用本文的体积边界保护。

PostProcessPipeline 每个装饰处理器运行前保存方块快照，按坐标最后一条操作比较处理结果。已生成的外墙边界或体块顶面方块若变为空气、remove 或被删除，则恢复原方块，并记录 `Exterior integrity` 日志，包含处理器名称和恢复数量。

边界使用编译器已解析的 BuildingVolume 三维并集，包括附楼及 slot 偏移。共同墙面不属于外边界；低附楼上方暴露的主体墙面仍属于外边界。不会用整栋包围盒填充 L 形缺口。

原始最终状态为空气的门窗、原本没有方块的位置、受保护的楼梯和通行空间不补块。保留非空气的材质和造型替换。地形适应器会主动移动坐标，跳过此比较以避免在原位置复制建筑。

本批检查的是**后处理破坏已有外壳**，不是全部建筑要求验收。不能发现生成器从未生成的墙面、构件合并阶段已发生的覆盖、屋檐等体块范围之外的缺失，也不证明方块实际写入世界。圆形体块只保护落在解析边界上的已有方块，不推断圆弧表面。楼梯与外墙碰撞仍由宿主适配和通行验证处理。

测试覆盖外墙删除、附楼顶面删除、材质替换、合法开口、L 形空缺、共享墙、不同高度外墙、楼梯预留空间及原地修改输入列表。

验证：`gradlew.bat build --offline` 成功，Java 519 项测试通过；架构检查 20 项已知债务、0 新增。源码 jar 重映射仍有已有 EmptyStackException 警告，运行模组 jar 构建成功。本批未修改 Python 后端。
