# 游戏内构件包导入

项目尚无历史资产依赖，不新增旧库迁移或旧引用映射。构件库提供选择 `.fccomponent.json`、服务端信息预览、确认入库、结果反馈的正常流程。

客户端用本机文件选择器选取文件，在后台有界读取一次内存快照，不向服务器发送文件路径。文件上限沿用 16 MiB，每个网络分块最多 20 KiB，每客户端 tick 最多发送两块；服务端检查声明长度与连续偏移，拒绝截断、重复或越界数据。

服务端按真实玩家绑定上传会话，最多 4 个待处理会话、总声明容量不超过 32 MiB。会话在 120 秒无活动后过期，断线、取消、停止服务器或确认完成均释放。接收阶段不创建构件库文件。上传完成后校验编码、协议、哈希、结构、作者变体规则与服务端依赖环境，保存不可变 Verified 快照，返回名称、尺寸、方块数、作者声明、许可、训练授权、版本与目标库。

预览是导入信息预览，不是三维场景预览。确认按钮消费当前玩家的会话，并重新核对真实保存上下文；权限或目标库变化时拒绝，不能悄悄换库。仅确认后调用既有内容去重事务，返回新增资产、新配置、补充来源或复用结果。确认不能重复消费，不改原包或主来源授权。

客户端请求使用随机会话 ID 关联异步读取、上传和响应，过期响应不更改新任务。切换连接或断线时清空本地状态；不支持导入协议的服务器不触发上传。预览与上传均可取消，确认提交期间等待服务器结果。新资产暂不自动生成缩略图，加载后的预览沿用现有构件工具。

本阶段不提供网络资源市场、批量包、来源编辑或旧库迁移；不会自动选择任何用户文件或导入实际资产。文件选择器及真实多人游戏交互需游戏内验收。

## 自动验证

当前工作区通过 `scripts/verify-component-assets.ps1` 隔离构建，128 项构件相关测试全部通过，失败与错误均为 0。新增 15 项：服务端会话 8 项、客户端状态 5 项、消息编解码边界 2 项。覆盖预览零写盘、快照隔离、一次性确认、来源授权保留、分块顺序/溢出/截断、玩家绑定、会话过期、断线清理、容量限制、权限变化、非法编码与依赖环境拒绝、异步响应关联及消息长度。文件选择、界面和网络注册已编译通过，尚未进行真实游戏内验收。

## 游戏内验收步骤

1. 在构件库点击导入，取消文件选择，确认库与目录不变；选择合法包后观察上传进度和服务端信息预览。
2. 对照名称、尺寸、方块数、来源声明、训练授权与目标库；预览到达时确认按钮应自动定位到可见区域，长许可文本可滚动。
3. 取消预览，确认没有新资产；再次选择并确认，核对实际选中 ID、目录刷新、构件加载及放置预览。
4. 重复导入同一包应复用；不同名称同内容应补充来源；同名不同内容分别保留；不同变化规则保留不同配置。
5. 在独立服务器分别用普通玩家和 OP 导入，核对私人/全局范围；预览后改变 OP 权限应要求重新预览。
6. 上传或预览时断线、超时、取消后重试，确认旧响应不串入新任务；不兼容或损坏包应拒绝，确认前始终不写库。

按来源导出入口、分块加载及远端缩略图已接通，见 [构件库完整性复核](COMPONENT_LIBRARY_COMPLETENESS.md)。导入确认前仍为信息预览，确认前的几何场景预览尚未实现；实际游戏验收仍待执行。
