# 构件捕获与建筑资产库开发设计

状态：开发方案；以下阶段只有明确标注已实现的部分代表现有能力。

## 目标与职责

LLM 负责空间、体量、立面节奏及构件需求；资产库提供作者制作的精细结构；确定性编译器负责变化权限、坐标、开洞、冲突与事务提交。建筑设计与检索允许有限往返：尺寸可协商时调整开间，锁定时更换候选。没有库的普通建筑仍须可以生成。

原型保留原件与作者意图。临时变体不修改原件；收藏变体保存引用原型的配方；实例保存宿主、位置、朝向和最终版本。手工修改后的衍生资产显式记录来源。

## 当前代码基础

- ComponentCaptureDraft：选区、宿主、锚点、朝向及连接器确认。
- ComponentToolJsonBuilder：捕获坐标、类别和标签序列化。
- ComponentStorage：全局、玩家及旧世界库；保存校验与原子写入。
- SegmentScaler / ComponentModelApi：固定端、中段重复或缩短、适配权限。
- ComponentRetriever / ComponentRanker：候选筛选、评分及实际适配。
- ComponentGenerationPipeline：捕获库权威路由、失败诊断。
- PromptSystemSections：目前普通建筑默认原生生成，捕获库需显式请求。

## 资产契约（拟议，不能直接当现有 JSON 使用）

原型包含 identity（命名空间、版本、哈希）、geometry（原始结构、局部坐标）、interfaces（宿主、安装点、洞口、净空）、adaptation（区域、周期、尺寸及比例约束）、appearance（形态、材料、套系）、provenance（作者、衍生来源、许可）。

实体占用、允许清洞和所需净空分别存储。洞口尺寸与构件外包围盒分别命名；旧 openingWidth/Height 仍按现有捕获坐标兼容，迁移时禁止静默改变含义。

用途类别稳定且允许扩展；标签开放，支持别名与语言归一。形态风格与材料风格分开；换材不能自动推断形态风格兼容。套系及家族表达端头、转角、尺寸成员和推荐搭配。

## 捕获交互（拟议）

1. 快捷捕获：选区、正面、安装点，立即支持原样预览。
2. 用途确认：类别、标签、宿主及洞口；自动建议须标记来源并可修改。
3. 变化编辑：用正面宽度/高度/厚度表达局部轴；可视化固定区、重复区、换材区及允许尺寸。
4. 安装试验：在示例宿主上检查原尺寸、边界尺寸、朝向与净空。

高级字段允许后补。未知变化权限默认锁定；复杂雕饰优先使用家族成员。整体体素缩放必须作者明确允许。多区域、周期、比例及功能方块完整性需要统一运行时与保存校验。

## 选型与建筑协作（分阶段实施）

需求包含角色、宿主、目标尺寸范围、锁定条件、视觉意图与替代策略。先检查实际装配可行性，再比较形态、材料、尺寸、变形损失、布局调整成本和套系协调。未知安装元数据不等于已验证。

原样优先须在风格与用途合适的候选之间比较，不得无条件压过更合适的变体。建筑级选择先形成协调候选集合，再分配实例，允许受控局部变化。

第一阶段保持现有接口与权威路由，先修正几何评分中的不允许缩放语义，并为同分候选建立稳定 ID 次序。后续再增加实际适配方案评分与可解释拒绝原因。不能把评分成功当成安装成功。

失败保留 NO_CANDIDATE、ADAPT_FAILED、LOAD_FAILED 区分；显式指定资产失败不可悄悄换成普通几何。可选细节与必要构件使用不同的失败策略。

## 社区协议（后续）

先实现离线构件包，再增加远端索引。包携带结构、规则、预览、作者命名空间、版本、哈希、游戏及模组依赖、来源和许可。安装前校验路径、体积、格式及依赖。远端包不执行任意代码。

建筑锁定资产版本和哈希，本地缓存保证复现。索引先查轻量元数据，按需下载结构。共享许可与模型训练授权独立记录；检索复用不要求先训练模型。

## 开发顺序与验收

1. 检索基础：固定尺寸不被误罚，同分次序可重复；保留现有适配权限及失败语义。
2. 捕获体验：局部轴、分区可视化、净空编辑；柱头柱脚延展后保持，门窗功能配对不破坏。
3. 需求与适配方案：实际适配后比较，返回解释；用窗、栏杆、柱完成一次建筑级案例。
4. 资产协议收敛：明确 Definition、Prototype、Archetype 职责，提供版本化迁移与导入导出。
5. 社区服务：搜索、套系、发布、衍生、缓存、锁定及离线复现。

自动调用提示的放开必须在第三阶段闭环验证后实施。首个案例须检查预览/实际 Patch 一致、锚点、开洞、保护区、失败事务和原件不变。每阶段分别报告单元验证与游戏内验证，不能相互替代。

## 实际适配结果选型（2026-10-30）

retrieveBestResolved 现在比较前 20 个初筛候选中的所有成功适配方案。候选报告的 SUCCESS 表示可适配，不代表被选中；最终选择以 result.sourceId 为准。每次成功尝试携带 fitScore：targetError 是已指定尺寸轴的最大相对误差，dimensionalChange 是相对原件各轴变化的最大值，二者限制在 0–1。

存在评分明细时，用 1-targetError 替换原几何评分，保留语义、风格、安装环境及用途维度；再减去 adaptationPenalty × dimensionalChange。selection.adaptationPenalty 默认为 0.10，限定在 0–1，非有限值恢复默认；旧查询没有 selection 时兼容默认。没有评分明细的兼容候选从原总分扣除 0.20 × targetError。相同最终分数按资源 ID 稳定选择。

每个候选的随机源从本次种子与资源 ID 派生，避免前面候选的随机消耗影响后续变体。评价仅衡量尺寸变化，尚不代表雕饰完整性、美学质量或世界安装合法性。实际形态损失、材料变化成本、套系协调和旧 retrieveBestWithVariant 路径统一仍待后续完成。
