# 所选社区来源的手动预览

入库或所选来源配方完成后，社区侧栏增加“加载所选来源用于预览”。需要先刷新本地目录；加载使用现有有界构件包传输读取同内容本地资产，客户端悬停几何来自该资产。绑定另行保留当前社区会话/任务凭据，不将本地别名或其首份许可视为所选来源。普通加载清除绑定，社区任务变化后旧绑定不能静默降级为普通放置。返回本地页时若仍在使用有效来源绑定，会保留该社区会话；显式断开或闲置到期仍会使绑定失效。

放置请求仅增加两个随机 UUID（会话、来源任务），不包含客户端收据、文件路径或包描述符。服务器从真实连接解析当前所选来源，并验证请求资产 ID。收据读取、别名内容核对和编译进入已有有界工作池；每次提交使用任务预算、45 秒期限及最新请求标识。新的构件/选区 Patch 预览请求、社区任务、断线或配置替换使旧结果不可发布。

编译使用 ComponentSourceBinding 的明确来源和既有作者规则/变换权限，记录并核对实际使用的收据及原包指纹。客户端的同内容几何不承担来源授权；服务器不得退回别名 A 的原包来替代选中的 B。后台结果只保留相对补丁和有界来源身份，不长期持有完整原包。

回到主线程后再次核对服务实例、连接对象、维度、距离、当前来源任务及最新请求，再进入既有权威 Patch 预览过滤、质量检查和票据确认。社区来源忽略 autoConfirm，请求只生成预览，不直接修改世界；最终应用继续由既有确认流程处理。普通预览也会使正在准备的旧社区预览失效。

本阶段没有把手动预览扩展为持久建筑资产锁；所选来源在编译结果和服务端票据日志中可追溯，长期固定仍通过已实现的私人配方。恢复后跨会话手动来源绑定、手动预览的持久依赖归档和真实游戏交互仍待后续实现。
