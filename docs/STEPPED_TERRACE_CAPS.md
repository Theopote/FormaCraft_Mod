# 退台露台封板

主体生成器在逐层轮廓缩进前一层，生成“当前层轮廓减去下一层轮廓”的露台封板。封板先于内部掏空、窗户和立面镂空处理，使用 FLOOR 材料，因此显式 `floor_block` 同样适用于露台。

封板只占一层方块，不填充上层房间，也不补满整个包围盒。原始平面形状过滤及院落空洞处理先执行，保留 L 形缺口和院落。最终顶层继续由既有屋顶逻辑负责；未启用退台时没有额外封板。

封板记录为 ROOF 表面，参与已有生成完整性检查、后处理外壳保护及开口覆盖权限。显式楼梯净空继续沿用通行预留机制；本批不调整楼梯放置策略。该规则不解决坡顶接缝、附楼间露台遮挡或露台栏杆设计。

自动推断入口在首次缩进封板下方停止，避免默认门洞删除露台。显式 `door_height` 保留用户要求，冲突时沿用表面覆盖诊断。

回归测试使用实际主体输出，检查两次退台封板、显式材料、平面缺口、房间保持空心、非零锚点及表面声明；完整编译样例检查默认入口接合。游戏中的露台观感和楼梯接合仍需实际测试。
