# 社区构件库侧栏

在现有构件库内增加本地 / 社区切换。进入社区页不自动联网；用户显式连接服务器已配置的社区服务，搜索与下载均通过既有游戏消息。客户端不能填写 URL 或服务器路径。[本人收藏的来源恢复](COMPONENT_COMMUNITY_RESTORE.md)不依赖远端服务配置。

首版只提供当前 offline-summary.v1 真正支持的类型精确匹配、标签全部匹配、游标分页。类型复用捕获工具的预设，也能根据自定义类型名称生成同一规范化键。暂不提供远端尚不支持的名称全文搜索、风格推荐或兼容性筛选。下一页沿用上次提交的查询快照，编辑筛选后须重新搜索。

结果按已验证的候选顺序展示，以 releaseId 选择，名称相同也不会混淆。作者、许可均标注为声明；数据校验与游戏运行兼容性分别展示。远端文字按纯文本清理和限制长度，不解释富文本、链接或格式代码。下载按钮明确写入服务端私人缓存，成功后显示等待入库的状态，不提供放置动作。

点击“返回本地构件库”时清除页面选择，未在使用有效手动来源绑定时关闭会话；切到其他工具标签时任务可在后台继续，断线由现有客户端状态机清理，闲置会话由服务器到期释放。滚动裁剪区域外不响应按钮或输入框，返回本地后清除焦点和旧命中区域。错误展示中文提示与有界错误码，服务未配置不要求用户填写网络地址。

验收覆盖查询构造、自定义类型、分页条件绑定、展示文本清理和候选身份映射；真实游戏中的窄侧栏、输入法、滚动和多人连接仍需人工验收。[可信服务配置](COMPONENT_COMMUNITY_CONFIGURATION.md) 已提供存档配置与管理员命令，[下载后入库确认](COMPONENT_COMMUNITY_INSTALL.md) 已接入，预览与确认分开，不自动放置。[所选来源手动预览](COMPONENT_COMMUNITY_PLACEMENT.md)提供明确加载入口和服务端来源复验。[所选来源配方](COMPONENT_COMMUNITY_RECIPES.md)在入库后提供名称及 X/Y/Z 编辑与显式收藏，使用已选来源，不改用本地复用别名。
