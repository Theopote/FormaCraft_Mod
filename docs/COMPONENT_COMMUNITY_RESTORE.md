# 跨会话恢复所选社区来源

本地收藏目录标记带社区收据的配方，恢复按钮改为“恢复社区原件并选择来源”。用户显式操作后打开恢复会话，提交本人配方 ID，在既有后台工作池中核对固定结果、原件快照、许可与独立收据，再恢复/复用本人私人资产。后台将已验证收据复制回当前存档私人缓存，新的随机会话/任务凭据用于手动预览及继续收藏。

原下载缓存删除、重连或重进存档后，不依赖旧任务凭据。恢复只读取本人私人配方，不接受用户 ID、路径或收据。非社区配方继续使用原普通恢复入口；损坏、缺失、其他玩家的配方或环境不匹配均拒绝，不能回退为其他来源。写入许可前取消可阻止资产恢复，许可后合法私人数据可能保留，但旧任务不能发布成功。

恢复是离线能力，不要求配置或启用远端社区服务。新增 OPEN_RESTORE 只在需要时创建本地任务服务，其后端没有 HTTP 客户端，搜索/下载明确拒绝。已有远端任务服务存在时复用该服务，但恢复过程不调用远端。管理员状态仍表示远端是否启用，配置重载或停用会清理现有恢复会话；之后用户仍可显式新建本地恢复会话。不会改写服务配置或自动启用网络。

会话路由身份仅用于协议关联，不因当前服务换了 authority 而重写原包发布者。客户端完整校验恢复文档、安装结果和收据的关联后，明确说明来自本人收藏，显示原尺寸、作者/许可/训练声明和历史来源发布标识；不自动加载或应用。用户刷新本地目录后，可明确加载已恢复的所选来源，继续使用强制待确认的手动预览。

本阶段恢复原件，不把收藏的适配结果冒充原件。原有配方结果仍可单独查看/重放；本轮不扩展手动预览的持久资产锁。真实游戏重连、恢复界面和最终应用需后续联调。
