# 玩家社区任务协调

新增服务端显式配置的任务协调器，负责搜索、续传下载和私人收据保存。没有新增社区 UI、客户端网络消息、自动安装或世界修改；配置仅接受可信服务端代码提供的 authority/URI，默认不创建服务或发起网络请求。

本阶段协调交互式单页搜索/单个下载，不是 AI 多需求选件事务。Snapshot 是服务端内存模型，不是现有游戏 payload；后续 UI 必须用独立有界分页/分块转发，不能把 128 KiB 搜索 JSON 塞入旧字符串消息。

## 会话和任务

每次 open/connect 创建新的随机会话 ID，替换同玩家旧会话并取消旧任务。每个玩家会话只保留一个当前任务，使用独立随机 taskId；新搜索或下载取消旧任务。结果发布必须同时匹配玩家、会话和当前任务；断线、会话替换、超时或取消后，旧 worker 即便返回也不能覆盖新状态。

协调器最多保留 32 个会话，使用独立的 2 个工作线程与 8 个排队位置。队列满时明确 budget_exceeded，不使用主线程回退执行。每会话每 60 秒固定窗口最多 30 次任务提交；搜索任务总期限 45 秒，下载与缓存任务 150 秒，排队时间也计入。主线程 tick/快照查询可到期取消任务；网络层继续使用自身更严格的超时。闲置会话 10 分钟后释放。取消只中止当前任务，不删除已验证收据或合法续传块。

闲置按最后一次任务提交或 connect 计算，轮询快照不延长保留时间。Snapshot 单独返回 catalogExpiresAt，过期候选即使仍可展示也不能下载；同一页以外的候选需重新搜索。Metrics 只供可信服务端查看工作线程、队列与会话数量。

搜索结果只保留当前页，最多 20 个描述符和 128 KiB JSON。下载请求必须提供当前搜索任务 ID 及候选 releaseId；描述符来自服务端已校验结果，不能由客户端改写 hash、路径或 URL。新搜索立即使旧候选失效；下载前还会执行已有详情、可交付状态与原包验证。完成下载的状态只表示私人收据就绪，不代表安装或建筑预览通过。

## 线程与提交

所有网络等待、包验证、续传文件和缓存读写都在有界 worker 池执行。协调器快照只复制有界内存状态；不访问 Minecraft 实体或读取磁盘。worker 使用配置时的不可变目标环境快照。

私人目录从服务器世界根和玩家 UUID 推导：`formacraft/community/players/{uuid}/downloads` 与 `staging`。目录逐级验证，不接受客户端文件路径。不同玩家/世界不会共用收据或暂存授权；可见状态中不返回本机路径或远端原始错误信息。

缓存新增 CommitGate，在对象目录与收据目录的原子 move 前执行协调器检查：短暂持有任务状态锁，确认任务未取消、未到期且仍属于当前会话，发放该次提交许可，然后在锁外执行 move。网络、验证和所有文件操作均不在状态锁内。取消先于许可时不得发布该份收据；取消不能撤回已经发放的许可，因此已获许可的有效对象/收据可能在取消后完成落盘，但过期任务不会得到“就绪”结果。不会为模拟取消而删除共用对象。

锁顺序要求：缓存层调用短 CommitGate，状态锁内不得调用文件操作、缓存读写、安装或网络。Future 取消不等于 worker 已退出，实际线程/队列始终由有界线程池限制；不把忽略中断的旧 worker 当空闲名额。

## 游戏生命周期

CommunityTaskService 注册断线、服务器 tick 和停服清理。未配置服务时钩子不创建网络客户端。configure 必须由服务器线程显式调用；替换配置取消旧服务。停服/替换通过非等待式 HTTP shutdown 与线程池 shutdownNow 释放任务，不在服务器线程等待网络退出。

业务 API 仍是可信服务端入口，调用者必须从当前游戏连接取得玩家 UUID 和会话 ID，不能信任客户端自报的用户身份。未来 UI 消息只携带任务/候选标识并由服务端解析；安装确认和来源绑定需另行接入，不在下载成功时自动调用。

## 验证范围

使用受控后端、临时世界目录和任务栅栏验证：旧任务忽略取消后晚回、重连、跨玩家查询、队列背压、排队取消、到期释放、候选过期与身份绑定、私人目录、缓存提交门槛和失败脱敏。生命周期钩子做编译验证，真实游戏内交互仍待验收。
